# Дашборд

Дашборд — страница, которую панель открывает первой. В боковом меню она
называется **Панель**. Она показывает, как работают сервер самой панели, ваши
узлы и ваши пользователи, и большую часть её содержимого вы выбираете сами.

## С чего начать {#getting-started}

Новая панель открывается с карточкой **С чего начать** над всем остальным. В
ней по порядку перечислены пять вещей, без которых ссылка клиента не
заработает: инбаунд, шаблон с этим инбаундом, узел, этот шаблон на узле и
пользователь. Каждый шаг ведёт на страницу, где он выполняется, и отмечается,
как только он выполнен. Карточка исчезает сама, когда готовы все пять шагов,
или когда вы нажимаете **Скрыть руководство**. Те же шаги разобраны в
[[start/index]].

## Полоса сводки {#the-summary-strip}

Ряд счётчиков под карточкой:

| Счётчик | Что он считает |
| --- | --- |
| **Пользователи** | все учётные записи, которые вы видите |
| **Пользователи онлайн** | учётные записи, передававшие трафик за последние 90 секунд |
| **Активные пользователи** | включённые учётные записи |
| **Подключённые узлы** | узлы, до которых панель сейчас достаёт, из общего числа ваших узлов |
| **Входящие** | [[~inbound\|инбаунды]] в пуле |
| **Шаблоны** | шаблоны |
| **Общий трафик** | всё, что передали все узлы с момента их добавления |

## Плитки {#tiles}

Под полосой находятся плитки: небольшие живые индикаторы, графики и сводки.
Нажмите **Плитки**, чтобы выбрать, какие показывать. Закреплённые плитки
сохраняются в вашей учётной записи, поэтому следуют за вами в любой браузер;
другие администраторы выбирают свои.

- **Перетащите** плитку за заголовок, чтобы переместить её.
- **×** в заголовке плитки открепляет её.
- Пока страница открыта, плитки обновляются каждые несколько секунд. Строка
  рядом с кнопкой **Плитки** показывает, сколько плиток закреплено и как часто
  они обновляются.

Новая учётная запись начинает с закреплёнными плитками сервера и парка.
Плитки узла сначала не закреплены: каждая описывает один узел, и вы сами
выбираете какой.

Плитки делятся на три группы, и дашборд показывает каждую группу в своём
разделе.

### Сервер: машина самой панели {#server-the-panel-s-own-machine}

Показываются в разделе **Состояние сервера** вместе с версией панели и
способом её установки.

| Плитка | Что показывает |
| --- | --- |
| **Система сервера** | версию панели, ядра CPU, память, диск и время работы |
| **Нагрузка ЦП сервера** | нагрузку как долю от ядер CPU, со средним и пиковым значением |
| **Память сервера** | занятую память на сервере панели |
| **Процесс сервера** | память, которую использует сама программа панели |
| **База данных** | тип и размер базы данных, число записей трафика и сколько в ней пользователей, узлов и инбаундов |
| **Резервные копии** | когда сделана последняя резервная копия, включено ли автоматическое резервное копирование и сколько архивов лежит на сервере. Время становится янтарным, если резервная копия просрочена. |
| **Лицензия** | лицензия или бесплатный уровень, срок действия и сколько пользователей и узлов использовано из лимита |

**Резервные копии** и **Лицензия** доступны только главному администратору:
другие учётные записи не видят их в списке плиток. См. [[use/backup]] и
[[use/licence]].

### Парк: все подключённые узлы {#fleet-every-connected-node}

Показываются в разделе **Обзор парка** вместе с числом подключённых узлов.

| Плитка | Что показывает |
| --- | --- |
| **Пропускная способность парка** | загрузку и отдачу по всем подключённым узлам, сейчас и за последние минуты |
| **Нагрузка по узлам** | по одной линии CPU на узел |
| **Память по узлам** | по одной линии памяти на узел |
| **Доли трафика** | долю каждого узла во всём трафике. Неподключённый узел показан серым вместе с его состоянием. |
| **Пользователи онлайн** | сколько учётных записей онлайн из общего числа |

### Узел: один узел за раз {#node-one-node-at-a-time}

Показываются в разделе **Живые плитки**. Ряд названий узлов над ними
выбирает, какой узел они описывают.

| Плитка | Что показывает |
| --- | --- |
| **Загрузка CPU**, **Память** | индикаторы для этого узла |
| **История нагрузки**, **История памяти** | то же самое за последние минуты |
| **Сеть** | пропускную способность этого узла |
| **Система** | машину: имя, адрес, CPU, нагрузку, диск, swap, время работы |
| **Узел NX** | программу узла: работает ли она, версию, время работы, трафик, пользователей онлайн |

Прочерк (**—**) в плитке означает, что узел не сообщил это значение. Это не
ноль.

## Состояние узлов {#node-status}

Таблица под плитками перечисляет все узлы с их **Статус**, **Аптайм**,
памятью (**RAM**), **Нагрузка** и **Трафик**. Наведите указатель на значение
трафика, чтобы увидеть отдачу, загрузку и долю во всём парке. Все подробности
и действия — на странице [[use/nodes]].

| Статус | Значение |
| --- | --- |
| `connected` | панель достаёт до узла, и узел обслуживает свою конфигурацию |
| `connecting` | панель подключается к узлу |
| `error` | панель не может достучаться до узла, или узел отказался от своей конфигурации. Причину показывает страница узлов. |
| `disabled` | вы выключили узел |

## Пользователи по трафику {#top-users-by-usage}

Список рядом с таблицей показывает восемь учётных записей с наибольшим
трафиком. Зелёная точка отмечает учётную запись, которая сейчас онлайн.
Нажмите на учётную запись, чтобы увидеть, на каких узлах она израсходовала
трафик за выбранный период (**Трафик по узлам**). Для этого нужно право
**Трафик, отчёты и состояние**.

## Что видит реселлер {#what-a-reseller-sees}

[[~reseller|Реселлер]] получает другой дашборд, только о своих клиентах:

- **Моя квота**: израсходованный трафик из его квоты, остаток, цикл сброса и
  срок действия его учётной записи.
- Счётчики: **Мои пользователи** (против его лимита пользователей),
  **Пользователи онлайн**, **Активные пользователи** и **Истекают ≤7 дн.**.
- **Мои пользователи**: список его учётных записей.

См. [[use/resellers]].
