# Общие настройки

**Настройки → Общие** — это то, как открывается сама панель, и несколько
общих для всей панели параметров. Большинство изменений адреса панели
вступают в силу после перезапуска, а менять их может только главный
администратор. Несколько портов, дополнительные хосты и пути и всё остальное,
чем может отвечать панель, находятся на [[use/ingress]], где изменение
применяется сразу.

::: warning
Неверный адрес, путь или параметр прослушивания может закрыть вам доступ к
панели. Любой из них можно вернуть из командной строки сервера, даже когда
панель не запущена. См. [[reference/cli]].
:::

## Адрес панели {#the-panel-s-address}

Карточка **Веб-сервер** определяет, где отвечает панель. Она показывает
один адрес панели. Как только [[use/ingress]] содержит больше, чем могут
описать эти поля, например второй порт, изменённое здесь значение
отклоняется с сообщением, которое указывает туда.

| Параметр | Что делает |
| --- | --- |
| **Домен панели (необязательно)** | Если задан, панель отвечает только на запросы к этому имени хоста. |
| **Базовый путь панели (необязательно)** | Панель работает по пути, например `/panel`. Запросы вне этого пути до страницы входа не доходят. |
| **IP прослушивания** | Адрес, на котором слушает панель. Пустое поле — все адреса, IPv4 и IPv6. |
| **Порт прослушивания** | Порт, на котором слушает панель. |

Мастер настройки предлагает случайный базовый путь. Оставьте его: он убирает
страницу входа с голого адреса панели, и без него не работают домены подписок
и веб-сайт, описанный ниже.

В Docker адрес прослушивания задаёт compose-файл, потому что там же находится
проброс порта, и поля об этом сообщают. Меняйте оба значения в compose-файле.
См. [[start/install-panel]].

Эти изменения вступают в силу после **Перезапустить панель**. Если сервер не
может занять новый адрес, панель возвращается к прежнему.

## HTTPS для панели {#https}

**HTTPS панели** определяет, как панель отдаёт свой веб-интерфейс:

| Вариант | Значение |
| --- | --- |
| **Сертификат из панели** | Сертификат из хранилища [[use/certificates\|сертификатов]], в том числе выпущенный через ACME. Продления доходят до панели без перезапуска. |
| **Файлы сертификата на диске** | **Файл SSL-сертификата** и **Файл SSL-ключа**: пути на сервере панели. |
| **Обычный HTTP (без сертификата)** | Без TLS. Пароли и ссылки подписок передаются открытым текстом. |

Мастер настройки начинает с самоподписанного сертификата из хранилища. Чтобы
использовать настоящий домен, выпустите для него сертификат ACME на странице
сертификатов, выберите его здесь и перезапустите панель.

Сертификат, которым вы управляете сами, должен включать и все домены подписок;
см. [[use/subscriptions#subscription-domains]].

## Веб-сайт для прочих адресов {#a-web-site-for-other-addresses}

**Каталог маскировки** принимает абсолютный путь на сервере панели. На
[[use/ingress]] это ответ по умолчанию **Статический сайт**, которым может
пользоваться любой слушатель или маршрут.
Запросы на
порт панели, которые не относятся ни к панели, ни к подписке, получают ответ
из этого каталога как от обычного веб-сайта, который вы предоставляете:
посадочной страницы, сайта компании, чего угодно, что подходит адресу.

- Нужен **Базовый путь панели (необязательно)**. Если панель стоит в корне,
  для сайта не остаётся адресов.
- Своего сайта панель не поставляет. Положите туда свои файлы и добавьте
  `404.html` для путей, у которых нет файла.
- Каталог не отдаёт список файлов, скрытые файлы и ссылки, ведущие за его
  пределы.
- API панели он не затрагивает: неаутентифицированный запрос к API
  по-прежнему получает ответ самой панели.
- Вступает в силу после перезапуска.

## Подписки и интеграции {#subscriptions-and-integrations}

Эта карточка задаёт, куда ведут ссылки подписок пользователей:
**Домены подписок (необязательно)**,
**Базовый путь подписок (необязательно)** и **Публичный адрес**. Они описаны
на странице [[use/subscriptions]] вместе с остальными настройками подписок.

## Зеркало наборов правил и каталог пресетов {#rule-set-mirror-and-preset-catalogue}

- **Зеркало наборов правил → Каталог хранения**: где панель хранит свою копию
  каждого набора правил. Абсолютный путь; если пусто, наборы лежат рядом с
  базой данных. См. [[rule-sets]].
- **Каталог пресетов → Каталог файлов**: откуда панель читает ваши
  собственные файлы пресетов. Карточка показывает действующие файлы. См.
  [[routing#your-own-presets]].

## Часовой пояс {#timezone}

**Часовой пояс панели** — пояс, в котором показываются все отметки времени в
панели, её журналах и на странице подписки и от которого отсчитывается начало
дня на графиках трафика. База часовых поясов встроена в панель, поэтому
работает любой пояс, как бы ни был настроен сервер. **По умолчанию сервера**
берёт пояс сервера.

## Графики трафика и журнал аудита {#usage-graphs-and-audit-log}

- **Графики трафика**: **Хранить выборки (дней)** и
  **Интервал выборки (секунды)** определяют, сколько истории трафика хранится
  для графиков на страницах списков. `0` дней выключает графики и удаляет
  сохранённое.
- **Журнал аудита**:
  **Записывать действия администраторов (журнал аудита)** фиксирует каждое
  создание, изменение и удаление вместе с аккаунтом, который это сделал.
  Записи хранятся **Хранить записи (дней)**. См. [[audit]].

Переключатель **Язык** здесь задаёт язык панели для вашего браузера.

## Защита входа {#login-protection}

Доверенные прокси, список разрешённых для входа и баны адресов находятся в
**Настройки → Безопасность** вместе с двухфакторной аутентификацией и
сессиями. См. [[use/security]]. Если панель стоит за обратным прокси или CDN,
задайте там **Доверенные прокси**, прежде чем полагаться на баны входа.

## Перезапуск панели {#restarting-the-panel}

**Перезапустить панель** перезапускает панель, чтобы вступили в силу изменения
адреса, пути, прослушивания и HTTPS, сделанные на этой странице. Изменениям на
[[use/ingress]] перезапуск не нужен. Когда панель вернётся, страница откроет
её по новому адресу — с изменённым портом, доменом, базовым путём или HTTPS —
на той же странице. За обратным прокси меняются только домен и базовый путь:
порт и схема принадлежат прокси. На новом домене нужно войти заново, а
самоподписанный сертификат, которого браузер ещё не видел, сначала покажет
предупреждение. Подключения пользователей это не затрагивает: узлы продолжают
работать во время перезапуска панели.
