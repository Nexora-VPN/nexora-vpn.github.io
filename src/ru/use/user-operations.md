# Группы и массовые операции

Страница пользователей умеет действовать сразу над многими учётными записями:
над отмеченными строками или над всеми учётными записями, попавшими в текущий
фильтр. Здесь описаны группы, два меню, с которых начинается массовая работа,
что делает каждая операция и что панель отказывается менять и почему.

<NxShot page="users" alt="Страница пользователей: отмечено несколько строк, рядом с кнопкой «Добавить» открыто меню массовых действий" />

## Группы {#groups}

Группа — произвольная текстовая метка учётной записи, которая вводится в поле
**Группа** формы пользователя. У неё нет настроек и своей страницы. Она нужна,
чтобы находить набор учётных записей и действовать над ними вместе.

- Выберите группу в **Фильтры → Группа** или нажмите на метку группы в списке,
  чтобы оставить только её учётные записи.
- [[~plan|Тариф]] записывает свою группу в каждую созданную им учётную запись.
  Других следов тариф в учётной записи не оставляет, поэтому по группе потом
  можно найти «всех, кому продан 30-дневный тариф».
- Пакетное создание может дать всем новым учётным записям одну группу (см.
  ниже).

## Два меню {#the-two-menus}

**Когда строки отмечены**, рядом с **Добавить** появляется кнопка массовых
действий. Её операции действуют ровно на отмеченные учётные записи.

**Кнопка ⋯ (Операции)** рядом с **Добавить** действует на весь список в
текущем фильтре, на всех страницах результатов, или на все учётные записи,
если фильтр не задан. Каждый пункт упоминает «текущий фильтр», а открытые им
диалоги перед подтверждением показывают, сколько учётных записей будет
затронуто.

| Операция | Отмеченные строки | Меню «Операции» |
| --- | --- | --- |
| Включить, отключить | **Включить**, **Отключить** | |
| Обнулить израсходованный трафик | **Обнулить трафик** | **Обнулить трафик текущего фильтра…** |
| Забыть зарегистрированные устройства | **Сбросить устройства** | |
| Добавить дни или трафик | **Продление и бонус** | **Продлить и начислить по текущему фильтру…** |
| Задать лимиты | **Задать лимиты** | |
| Выгрузить список CSV | **Скачать CSV** | **Скачать CSV текущего фильтра** |
| Выгрузить конфигурации | **Скачать пакет конфигов** | |
| Удалить | **Удалить** | **Удалить истёкших пользователей…** |
| Создать много учётных записей | | **Создать пользователей пакетом…** |

## Что делает каждая операция {#what-each-operation-does}

### Включение и отключение {#enable-and-disable}

**Отключить** выключает учётные записи, и они остаются выключенными, пока их
не включит человек: панель не возвращает их сама, даже если они в пределах
лимитов. **Включить** снова включает их, кроме учётных записей с прошедшим
сроком или превышенным объёмом, которые панель сразу же выключила бы снова.
О них сообщается как об оставшихся выключенными. См.
[[use/users#disabling-and-enabling]].

### Обнуление трафика и сброс устройств {#reset-traffic-and-reset-devices}

**Обнулить трафик** возвращает израсходованный трафик учётных записей к нулю.
Итоги за всё время сохраняются.

**Сбросить устройства** забывает все устройства, которые учётные записи
зарегистрировали в рамках лимита устройств. Места освобождаются. Устройства,
уже получившие конфигурацию, продолжают работать.

### Продление и бонус {#extend-and-gift}

Добавляет дни к сроку действия и трафик к объёму:

- **Добавить дней**: до десяти лет в любую сторону. Отрицательное число
  забирает дни.
- **Добавить трафика**: в ГБ. Отрицательное число забирает трафик.
- **Отсчитывать истёкшие аккаунты от сегодняшнего дня**: если это отмечено,
  учётная запись, истёкшая десять дней назад и получившая 30 дней, получит
  30 дней от сегодняшнего дня, а не 20. Неистёкшие учётные записи по-прежнему
  прибавляют дни к своей дате.

Чтобы сдвинуть дни, нужен срок действия, а чтобы добавить трафик — объём.
Бессрочная учётная запись или запись с безлимитным трафиком пропускается в
этой части, и об этом сообщается.

Программы, работающие через API панели, могут добавлять и календарные месяцы
(см. [[reference/api]]).

### Задать лимиты {#set-limits}

Задаёт **Объём**, **Истекает**, **Ограничение скорости**, **Лимит адресов**,
**Лимит устройств** и **Периодический сброс** для всех выбранных учётных
записей. Отметьте только те поля, которые хотите изменить; остальные останутся
в точности как были.

- Указание **Истекает** переводит учётные записи на фиксированную дату:
  срок, отсчитываемый от первого подключения, заменяется датой.
- Выключение периодического сброса очищает также его цикл и следующую дату.

### Выгрузка {#exports}

**Скачать CSV** — таблица, где на каждую учётную запись приходится одна
строка с её ссылкой на подписку: список, чтобы передать кому-то.
**Скачать пакет конфигов** — zip-архив с клиентскими конфигурациями всех
учётных записей.

::: warning
Выгрузка содержит ссылку на подписку каждой учётной записи, а она не хуже
самой учётной записи. Панель записывает каждую выгрузку в
[[use/audit|журнал аудита]], даже когда журналирование изменений выключено.
:::

### Удаление и удаление истёкших пользователей {#delete-and-delete-expired-users}

**Удалить** безвозвратно удаляет отмеченные учётные записи.

**Удалить истёкших пользователей…** удаляет все учётные записи, срок которых
истёк больше указанного числа дней назад (по умолчанию 30), включая те,
которые панель уже выключила. Фильтры страницы при этом не учитываются.
Учётные записи с отсчётом от первого подключения, которые так и не начались,
не затрагиваются. Перед подтверждением диалог показывает, сколько учётных
записей будет удалено.

## Создание многих пользователей по шаблону имени {#creating-many-users-from-a-name-pattern}

**Создать пользователей пакетом…** создаёт за один раз пакет учётных записей,
до 500 штук, у каждой свои учётные данные.

1. Укажите **Сколько** и **Шаблон имени** со счётчиком или случайной частью:

   | В шаблоне | Превращается в |
   | --- | --- |
   | `{n}` | счётчик: 1, 2, 3… |
   | `{nnn}` | счётчик, дополненный до трёх цифр: 001, 002… |
   | `{r}` | шесть случайных символов |
   | `{r3}` | три случайных символа |

   `shop-{nnn}` даёт `shop-001`, `shop-002` и так далее. Случайная часть даёт
   имена, которые соседу не угадать. В шаблоне может быть не больше одного
   счётчика и сколько угодно случайных частей. **Начать с** задаёт первое
   значение счётчика.
2. Задайте пакету **Группа**, чтобы потом его найти.
3. Выберите тариф или задайте лимиты и шаблоны, как для одного пользователя.
4. Нажмите **Создать**.

Занятое имя пропускается, поэтому повторный запуск того же пакета заполняет
пропуски. Когда пакет готов, скачайте список (**Скачать список**) или пакет
конфигураций для передачи. Если лицензия или лимит пользователей реселлера
остановит пакет на полпути, диалог сообщит, сколько создано и сколько места
осталось.

## Что отклоняется и почему {#what-is-refused-and-why}

Некоторые операции не могут изменить некоторые учётные записи. Панель
применяет операцию к остальным и сообщает об отклонённых, а не проваливает
весь выбор.

| Отклоняется | Почему |
| --- | --- |
| Включение учётной записи с прошедшим сроком или превышенным объёмом | она снова выключится в течение минуты. Сначала продлите её. |
| Добавление дней бессрочной учётной записи | нет даты, которую можно сдвинуть |
| Добавление трафика учётной записи с безлимитным трафиком | нет предела, который можно поднять |
| Любое изменение учётной записи вне лицензии | она доступна только для просмотра, пока вы снова не уложитесь в лимит. Удалить её всё равно можно. См. [[use/licence]]. |
| **Продление и бонус** и **Задать лимиты** для реселлера, который продаёт только по тарифам | лимиты его учётных записей — это лимиты тарифа, и менять их можете только вы |
| Любое изменение для реселлера, у которого выключено **Может изменять и удалять пользователей** | он может создавать учётные записи и выгружать их, но не менять и не удалять |

Если долгая операция прервалась, отчёт показывает, какие учётные записи уже
обработаны. Повторный запуск доводит дело до конца.
