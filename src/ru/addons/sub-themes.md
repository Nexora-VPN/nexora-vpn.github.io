# Создание темы страницы подписки

Эта страница для тех, кто хочет, чтобы пользователи видели ваш собственный
дизайн, открыв адрес своей подписки в браузере. Тема заменяет
[[~subscription-page|страницу подписки]] для всех пользователей панели. Это
один HTML-файл с картинками и стилями рядом, который панель заполняет
данными пользователя. Выбор темы и другие настройки страницы описаны в
[[use/subscriptions#the-subscription-page]].

## Что такое тема {#what-a-theme-is}

Тема — это каталог в каталоге тем панели:

```
sub-themes/
└── aurora/
    ├── index.html     the page (or sub.html)
    ├── style.css
    └── logo.svg
```

- `index.html` — это [Go `html/template`](https://pkg.go.dev/html/template):
  обычный HTML с подстановками `{{ … }}`, которые панель заполняет при
  каждом посещении. Панель экранирует каждое значение для того места, куда
  оно попадает, поэтому примечание пользователя не может добавить на
  страницу разметку.
- Остальные файлы каталога отдаются по адресу `{{ .AssetBase }}/<name>`:
  `<link rel="stylesheet" href="{{ .AssetBase }}/style.css">`. Файлы, имя
  которых начинается с точки, не отдаются никогда.
- Имя каталога — это имя темы в панели: буквы, цифры, `.`, `_` и `-`, не
  длиннее 64 символов.
- Постоянный `<title>` даёт теме имя в списке выбора панели. Если в
  заголовке есть подстановка, в списке остаётся имя каталога.
- Сборки нет. Панель перечитывает файл в течение нескольких секунд после
  правки, без перезапуска.
- Тема, которая не загрузилась или не отрисовалась, заменяется встроенной
  фиолетовой страницей, поэтому ошибка никогда не лишает пользователя
  подписки. Что пошло не так, записывается в журнал панели.

Тема может только оформлять то, что ей передаёт панель. К базе данных,
диску и сети у неё доступа нет.

## Начните со стартовой темы {#start-from-the-starter}

Публичный репозиторий
[`github.com/nx-panel/sub-themes`](https://github.com/nx-panel/sub-themes)
под лицензией MIT содержит:

| Каталог | Что это |
| --- | --- |
| `starter/` | Самая маленькая полная страница с комментариями, чтобы её копировать: статус, расход, срок действия, QR-код, кнопки приложений, каждая конфигурация, файлы конфигурации, уведомления и обновление на лету. Один HTML-файл и одна таблица стилей. |
| `builtin/violet/`, `builtin/amber/` | Две собственные страницы панели. Больше по объёму, и из них удобно заимствовать: вкладки, кольцо расхода, график истории трафика. |
| `check/` | `go run ./check` разбирает каждую тему так же, как это делает панель. |

1. Скопируйте `starter/` в каталог с именем вашей темы.
2. Положите его на панель (см. ниже) и откройте страницу пользователя.
3. Меняйте HTML и таблицу стилей. Удалите любой ненужный раздел: разделы
   не зависят друг от друга.
4. Запустите `go run ./check` в репозитории, прежде чем устанавливать тему
   или делиться ею.

## Установка и предпросмотр {#install-and-preview}

1. Скопируйте каталог темы в каталог тем на сервере панели:
   `/var/opt/nx-panel/sub-themes/` при стандартной установке,
   `./sub-themes/` рядом с compose-файлом в Docker. Главный администратор
   может указать другое место в поле **Каталог тем**.
2. В **Настройки → Подписки → Страница подписки** нажмите
   **Пересканировать каталог тем** и выберите тему в поле **Тема**.
3. Откройте адрес подписки пользователя, добавив `/page`, например
   `https://sub.example.com/sub/<token>/page`. Этот адрес всегда показывает
   страницу, даже приложению.
4. Добавьте `?lang=fa` (или `en`, `ru`, `zh`), чтобы увидеть страницу на
   другом языке.

Чтобы попробовать тему, не переключая на неё всех пользователей, задайте
эту тему в оформлении и назначьте его тестовому [[~reseller|реселлеру]] или
маршруту на тестовом хосте ([[use/ingress#brandings]]). Тему увидят только
подписки, которые берут это оформление.

## Данные, которые получает тема {#the-data-a-theme-receives}

Страница заполняется из одного значения, которое в шаблоне записывается как
`.`. К полям обращаются по именам ниже: `{{ .User.Name }}`,
`{{ .Usage.UsedText }}`. Внутри `{{ range }}` значение `.` — это текущий
элемент; к значению страницы обращайтесь через `$`, как в
`{{ index $.T "copy" }}`.

### Учётная запись: `.User` {#the-account-user}

| Поле | |
| --- | --- |
| `.Name`, `.Remark`, `.Desc`, `.Group` | Имя учётной записи, примечание, описание и метка |
| `.SubID` | Токен подписки |
| `.Enable` | Включена ли учётная запись |
| `.Online` | Был ли трафик за последние 90 секунд |
| `.OnlineAt` | Время последнего трафика в секундах Unix; `0`, если трафика не было |
| `.Status` | Одно слово: `active`, `disabled`, `pending`, `expired` или `limited`. `disabled` важнее остальных; `pending` — тариф, который начинается с первого подключения и ещё не начался |

### Трафик: `.Usage` {#traffic-usage}

| Поле | |
| --- | --- |
| `.Up`, `.Down`, `.Used` | Байты за текущий период |
| `.Total` | Квота в байтах; `0`, если лимита нет |
| `.Remaining` | Оставшиеся байты |
| `.Percent` | От `0` до `100`; `0`, если лимита нет |
| `.Unlimited` | Лимита трафика нет |
| `.UsedText`, `.TotalText`, `.RemainingText` | То же, записанное для людей, например `2.0 GB`. `.RemainingText` равно `∞`, если лимита нет |
| `.TotalUp`, `.TotalDown`, `.Lifetime`, `.LifetimeText` | Итоги, которые сохраняются после периодического сброса |

### Срок действия и сброс: `.Expire`, `.Reset` {#expiry-and-reset-expire-reset}

| Поле | |
| --- | --- |
| `.Expire.At` | Секунды Unix; `0`, если срок не ограничен |
| `.Expire.Never`, `.Expire.Expired` | Срок не ограничен; срок уже истёк |
| `.Expire.Days` | Оставшиеся дни с округлением вверх; `0` после истечения |
| `.Expire.Pending` | Тариф начинается с первого подключения и ещё не начался |
| `.Expire.Duration` | Длительность тарифа в секундах; `0` для фиксированной даты |
| `.Reset.Auto`, `.Reset.Days`, `.Reset.Next` | Периодический сброс трафика: включён или нет, раз в сколько дней и когда следующий, в секундах Unix |

::: warning Проверьте `.Expire.Pending`, прежде чем выводить дату
У тарифа, который начинается с первого подключения, предварительная дата,
и она сдвигается, когда пользователь подключается. `.Expire.Days` тогда
равно всему сроку тарифа. Напишите что-то вроде «30 дней с первого
подключения», как это делает стартовая тема.
:::

### Способы подключения: `.Configs`, `.Links`, `.Apps` {#ways-to-connect-configs-links-apps}

`.Configs` — по одной записи на каждое подключение пользователя:

| Поле | |
| --- | --- |
| `.Name` | Имя записи, как его показывают приложения |
| `.Protocol`, `.Network`, `.Security` | Например, `vless`, `ws` и `reality`, `tls` или `none` |
| `.Address` | Сервер и порт, готовые к показу: `203.0.113.10:443`, `[2001:db8::1]:443` |
| `.Server`, `.Port` | То же по отдельности |
| `.Link` | Ссылка для импорта |

Показывайте `.Address`. Если самому написать `{{ .Server }}:{{ .Port }}`,
сервер IPv6 превратится в `2001:db8::1:443`, что не читается ни как адрес,
ни как порт.

`.Links` — те же ссылки для импорта простым списком.

`.Apps` — файлы конфигурации для пользователей WireGuard, OpenVPN и
OpenConnect: `.Name`, `.Type`, `.FileName` и `.Content`, весь файл.
Предложите QR-код, скачивание и кнопку копирования:

```html
{{ range .Apps }}
  {{ $code := qr .Content }}
  {{ if $code }}{{ $code }}{{ else }}<p>{{ index $.T "qrTooBig" }}</p>{{ end }}
  <a download="{{ .FileName }}" href="{{ dataURI "text/plain" .Content }}">{{ index $.T "download" }}</a>
  <button data-copy="{{ .Content }}">{{ index $.T "copy" }}</button>
{{ end }}
```

### Подписка: `.Sub` {#the-subscription-sub}

| Поле | |
| --- | --- |
| `.URL` | Адрес подписки пользователя |
| `.URLs` | Адрес для каждого формата, читается как `{{ index .Sub.URLs "clash" }}`: `clash` — это `<subscription>/clash`, `singbox` — `/singbox`, `xray` — `/xray`, `plain` — `/plain`, а `v2ray` — сам адрес |
| `.UpdateInterval` | Сколько часов приложениям велено ждать между обновлениями |
| `.Incy`, `.V2RayTun` | Готовые ссылки импорта для INCY и V2RayTun, зашифрованные, как только вы сохраните ключ приложения ([[use/subscriptions#encrypted-import-links]]). Используйте каждую целиком как `href` |

### История трафика: `.Chart` {#the-traffic-history-chart}

Трафик пользователя, уже разложенный на столбцы, поэтому страница рисует
его без скриптов.

- `.Chart.Recording` равно false, если панель не хранит историю трафика.
  Тогда ничего не рисуйте.
- `.Chart.Ranges` — периоды по порядку: 24 часовых столбца, затем 7 и 14
  дневных. У каждого есть `.Key`, `.LabelKey` (фраза в `.T`), `.Default`
  (тот, что показывается первым), `.Width`, `.Empty`, `.MaxText`,
  `.TotalText` и `.Points`.
- Каждая точка — один столбец: `.At`, `.Label`, `.Up`, `.Down`, `.Text` и
  его положение `.X`, `.W`, `.DownY`, `.DownH`, `.UpY`, `.UpH`.

```html
{{ range .Chart.Ranges }}{{ if .Default }}
<svg viewBox="0 0 {{ .Width }} {{ $.Chart.Height }}" preserveAspectRatio="none">
  {{ range .Points }}
  <rect x="{{ .X }}" y="{{ .DownY }}" width="{{ .W }}" height="{{ .DownH }}" fill="#6d4aff"/>
  <rect x="{{ .X }}" y="{{ .UpY }}" width="{{ .W }}" height="{{ .UpH }}" fill="#b9a8ff"/>
  {{ end }}
</svg>
{{ end }}{{ end }}
```

Столбцы начинаются с местной полуночи и начала часа по времени панели. Они
показывают трафик, который действительно прошёл по сети, а он может
отличаться от `.Usage` на узле с множителем трафика или после сброса.
Встроенные страницы переключаются между периодами радиокнопками, без
скриптов.

### Ваши настройки и остальное {#your-settings-and-the-rest}

| Поле | |
| --- | --- |
| `.Panel.Title`, `.Panel.SupportURL`, `.Panel.Announce` | **Заголовок профиля**, **Ссылка на поддержку** и **Объявление** |
| `.Panel.Version` | Версия панели |
| `.Notices` | Короткие предупреждения для пользователей, уже переведённые, каждое с постоянным `.Key` и своим `.Text`. Перебирайте их в цикле, тогда уведомление, добавленное позже, появится без изменений в вашей теме |
| `.Lang`, `.Dir` | Язык страницы (`en`, `fa`, `ru`, `zh`) и направление (`ltr`, `rtl`) |
| `.T` | Фразы встроенной страницы на этом языке: `{{ index .T "copy" }}` |
| `.AssetBase` | Адрес, по которому отдаются собственные файлы темы |
| `.Now`, `.Timezone` | Время посещения в секундах Unix и часовой пояс панели |

## Вспомогательные функции {#helper-functions}

| Функция | Пример |
| --- | --- |
| `bytes` | `{{ bytes .Usage.Up }}` → `2.0 GB` |
| `date`, `datetime` | `{{ date .Expire.At }}` → `2026-11-03` |
| `when` | `{{ when .User.OnlineAt .T }}` → `Today 09:30` |
| `num` | `{{ num .Expire.Days }}` → `40` |
| `qr` | `{{ qr .Sub.URL }}` → QR-код как встроенный SVG или ничего, если текст слишком длинный для QR-кода |
| `dataURI` | `href="{{ dataURI "text/plain" .Content }}"` для скачивания |
| `b64` | `{{ b64 .Sub.URL }}` → base64 |
| `default` | `{{ default "Subscription" .Panel.Title }}` |
| `hasPrefix` | `{{ if hasPrefix "vless" .Protocol }}…{{ end }}` |
| `json` | `<script>var configs = {{ json .Configs }}</script>` |
| `urlquery` | Кодирует значение процентной кодировкой, для адреса, который собирается внутри скрипта |

На персидской странице `date`, `datetime` и `when` пишут дату по
солнечной хиджре, а они же, `bytes` и `num` пишут персидские цифры:
`{{ date .Expire.At }}` даёт `۱۴۰۵/۰۸/۱۲`. Пропускайте через `num` любое
число, которое выводите сами, но никогда не адрес, порт или ссылку.
Соединяйте два значения через `{{ index .T "sep" }}`: на большинстве языков
это ` · `, а на персидском — `، `.

Всегда сохраняйте результат `qr` в переменной и проверяйте его, как в
примере с `.Apps` выше. У длинного файла конфигурации нет QR-кода, и
непроверенный `qr` оставляет пустое место.

## Кнопки, которые добавляют подписку в приложение {#buttons-that-add-the-subscription-to-an-app}

Каждое приложение открывает свой вид ссылки:

| Приложение | `href` | Где адрес |
| --- | --- | --- |
| Happ | `happ://add/{{ .Sub.URL }}` | В пути |
| V2RayTun | `{{ .Sub.V2RayTun }}` | Вся ссылка |
| INCY | `{{ .Sub.Incy }}` | Вся ссылка |
| Streisand | `streisand://import/{{ .Sub.URL }}` | В пути |
| Hiddify | `hiddify://import/{{ .Sub.URL }}` | В пути |
| Shadowrocket | `shadowrocket://add/sub://{{ b64 .Sub.URL }}` | В base64, в пути |
| v2rayNG | `v2rayng://install-sub?url={{ .Sub.URL }}` | В параметре запроса |
| V2Box | `v2box://install-sub?url={{ .Sub.URL }}&name={{ .Panel.Title }}` | В параметре запроса |
| NekoBox | `sn://subscription?url={{ .Sub.URL }}&name={{ .Panel.Title }}` | В параметре запроса |
| Приложения sing-box (SFA, SFI) | `sing-box://import-remote-profile?url={{ index .Sub.URLs "singbox" }}` | Форматный адрес, в параметре запроса |
| Приложения Clash (Clash Meta, mihomo) | `clash://install-config?url={{ index .Sub.URLs "clash" }}` | Форматный адрес, в параметре запроса |

Пишите значение после `?url=` как есть. Шаблон сам кодирует его, а
повторное кодирование через `urlquery` даёт адрес, который не прочитает ни
одно приложение. Приложения Clash и sing-box получают адрес своего формата,
поэтому импорт работает независимо от того, распознала панель приложение
или нет.

## Обновление расхода на лету {#keep-usage-live}

Страница рисуется один раз, когда её открывают. Чтобы расход и точка
онлайна оставались актуальными, запрашивайте те же данные в JSON:

| Адрес | Что возвращает |
| --- | --- |
| `<subscription>/info` | Всё перечисленное выше в JSON, с именами в нижнем регистре (`usage.usedText`, `user.online`). Ссылки для импорта, содержимое файлов конфигурации и график не включаются |
| `<subscription>/info?chart=1` | То же вместе с графиком |

```html
<span data-info="usage.usedText">{{ num .Usage.UsedText }}</span>
<script>
  var INFO = {{ .Sub.URL }} + "/info";
  setInterval(function () {
    fetch(INFO, { cache: "no-store" }).then(function (r) { return r.json() }).then(function (info) {
      document.querySelectorAll("[data-info]").forEach(function (el) {
        el.textContent = el.dataset.info.split(".").reduce(function (v, k) { return v && v[k] }, info)
      })
    })
  }, 30000)
</script>
```

Значение, выведенное внутрь `<script>`, само записывается как строка
JavaScript. Числа в JSON приходят западными цифрами: стартовая тема
показывает, как превратить их в персидские на персидской странице.
Запрашивайте данные не чаще раза в 30 секунд, а график — только когда
перерисовываете его.

## Языки и письмо справа налево {#languages-and-right-to-left}

Язык страницы берётся из `?lang=` в адресе, иначе из браузера, иначе
английский.

- Поставьте `lang="{{ .Lang }}" dir="{{ .Dir }}"` на `<html>`. Персидские
  страницы пишутся справа налево.
- Пишите таблицу стилей на логических свойствах (`margin-inline-start`,
  `border-inline-start`, `text-align: start`), чтобы один набор правил
  раскладывал страницу в обоих направлениях.
- Берите слова из `.T` или держите свои для всех четырёх языков. Слово,
  которого нет на одном из языков, оставляет пустой элемент.

## Правила, которые стоит соблюдать {#rules-worth-keeping}

- **Ничего не загружайте с другого хоста.** Пользователи открывают эту
  страницу до того, как подключили VPN, часто в сети, где CDN шрифтов и
  скриптов заблокированы. Тема, которая ждёт такой CDN, показывает пустую
  страницу. Кладите шрифты и картинки в каталог темы или используйте
  системные шрифты.
- Проверяйте `qr`, прежде чем выводить его.
- Проверяйте `.Expire.Pending`, прежде чем выводить дату.
- Показывайте `.Address`, а не `.Server` и `.Port`, соединённые вручную.
- Перебирайте `.Notices` в цикле, а не пишите их текст сами.

## Поделитесь своей темой {#share-your-theme}

Отправьте pull request в
[`nx-panel/sub-themes`](https://github.com/nx-panel/sub-themes) с вашей
темой в новом каталоге верхнего уровня и коротким `README.md` со
снимком экрана. В README репозитория перечислено, что должна делать тема
в нём. Все темы там под лицензией MIT, поэтому операторы могут менять их
под свой сервис.
