# VMess

VMess — старший родственник VLESS: один идентификатор на пользователя, тот же
выбор транспортов и те же режимы TLS. Большинство операторов предлагают
вместо него VLESS, а VMess держат для пользователей, чьё приложение, роутер
или привычка его ждут.

## Для чего он нужен {#what-it-is-good-for}

- **Совместимость.** VMess читает любое семейство приложений: ссылки,
  приложения Clash (mihomo), приложения sing-box и приложения на базе Xray.
- **Работа без TLS за CDN.** VMess сам шифрует полезную нагрузку, поэтому
  инбаунд WebSocket или gRPC без TLS за CDN, который завершает TLS, всё равно
  не даёт CDN читать трафик. Для VLESS ту же задачу решает
  [[protocols/vless-encryption|VLESS Encryption]].

## Создание {#create-it}

**Входящие → Добавить**, тип `vmess`. Общая форма описана в [[use/inbounds]].

| Вкладка | Что задать |
| --- | --- |
| **Basic** | **Port** |
| **Transport** | `tcp (none)` или `ws`, `grpc`, `httpupgrade`, `xhttp`…, чтобы поставить его за CDN |
| **TLS** | **TLS** с [[~certificate\|сертификатом]], **REALITY** или **Нет** |
| **Multiplex** | по желанию; см. ниже |

На вкладке **Protocol** заполнять нечего. Каждого пользователя определяет
**UUID** на его вкладке **Учётные данные**, который панель создаёт для каждой
учётной записи; клиентские файлы пишутся с настройками, которых ждёт любое
современное приложение (без alter id, автоматический шифр).

## За CDN {#behind-a-cdn}

С транспортом `ws`, `grpc`, `httpupgrade`, `xhttp` или `http` и с TLS или без
TLS (но не с REALITY) его может нести [[~front|доменный фронт]]. См.
[[use/fronting]].

## Multiplex {#multiplex}

Вкладка **Multiplex** позволяет приложениям, которые открывают несколько
соединений поверх одного, использовать это с этим инбаундом. Такая настройка
есть в приложениях sing-box и Clash. Она не связана с переключателем **Mux** в
приложениях на базе Xray, который должен оставаться выключенным: если он
включён, соединение не устанавливается, а приложение никак это не объясняет.

## Клиентские приложения {#client-apps}

| Формат | |
| --- | --- |
| Ссылка (`vmess://`) | да |
| Приложения Clash | да, кроме транспортов `quic`, `xhttp` и `mkcp` |
| Приложения sing-box | да, кроме `xhttp` и `mkcp` |
| Приложения на базе Xray | да, кроме `http` (HTTP/2) и `quic` |
