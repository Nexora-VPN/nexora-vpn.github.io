# Первый пользователь за десять минут

Эта страница ведёт от подключённого узла до первого клиента, чьё приложение
подключается. Нужны завершённая [[setup-wizard|настройка]] и один узел со
статусом **connected** ([[add-node]]).

Пользователь получает рабочую ссылку, когда есть пять вещей, именно в таком
порядке: [[~inbound|инбаунд]], [[~template|шаблон]], который его содержит,
узел с этим шаблоном и [[~user|пользователь]], который в шаблон входит.
Карточка **С чего начать** на главной странице следит за теми же шагами.

## 1. Создайте инбаунд из пресета {#_1-create-an-inbound-from-a-preset}

Инбаунд — это протокол и порт, к которым подключаются ваши пользователи.

<NxShot page="inbound-new" alt="Добавление инбаунда из пресета, VLESS + REALITY первым в списке" />

1. Откройте **Входящие** и нажмите **Из пресета**.
2. Выберите **VLESS + REALITY**. Обычно это первый инбаунд: ему не нужны
   свой домен и сертификат.
3. Откроется обычная форма инбаунда, уже заполненная. Пока ничего не
   создано. Проверьте порт; остальное можно оставить, как задал пресет.
4. Сохраните. Панель сама создаёт пару ключей REALITY и short ID, так что
   генерировать и вставлять ключи не нужно.

Все поля потом можно менять, и инбаунд не помнит, из какого пресета он
создан. Другие пресеты и все параметры описаны в [[use/inbounds]], сам
протокол — в [[vless-reality]].

## 2. Добавьте его в шаблон {#_2-put-it-in-a-template}

Шаблон — это то, что обслуживает узел: инбаунды, аутбаунды, эндпоинты и
маршрутизация.

1. Откройте **Шаблоны** и добавьте шаблон. Укажите **Название**.
2. В разделе **Входящие** выберите инбаунд из шага 1.
3. Сохраните.

Вкладки маршрутизации и DNS могут подождать. Когда они понадобятся, см.
[[use/templates]].

## 3. Дайте узлу шаблон {#_3-give-the-node-its-template}

1. Откройте **Узлы** и измените свой узел.
2. Выберите шаблон в поле **Шаблон (входящие + исходящие + эндпоинты +
   маршрутизация)**.
3. Сохраните и дождитесь, пока узел снова покажет **connected**.

Без шаблона узел ничего не обслуживает. Теперь откройте порт инбаунда в
файрволе сервера узла, если файрвол работает.

## 4. Создайте пользователя {#_4-create-a-user}

<NxShot page="user-new" alt="Форма нового пользователя: имя, объём, срок и шаблоны" />

1. Откройте **Пользователи** и добавьте пользователя.
2. Укажите **Название**. Задайте **Объём** в ГБ (0 — без ограничения) и
   **Истекает** или отметьте **Начать с первого подключения** и укажите
   **Длительность (дней)**, чтобы срок пошёл с первого подключения клиента.
3. Оставьте в поле **Шаблоны** значение **Все шаблоны**. Новый пользователь
   по умолчанию получает доступ ко всем шаблонам.
4. Сохраните. Учётные данные создаются автоматически.

Тарифы, ограничения и всё остальное в этой форме описаны в [[use/users]].

## 5. Отправьте ссылку в приложение {#_5-send-the-link-to-an-app}

В строке пользователя откройте **QR / ссылки**.

- **Подписки** — адрес [[~subscription|подписки]] пользователя и его
  QR-код. Обычно выдают именно его: приложение само заново его загружает,
  поэтому дальнейшие изменения доходят до клиента без новой ссылки.
- **Ссылки** — по одной ссылке на каждую запись, для приложения, которое
  принимает отдельные ссылки.

Импортируйте в приложение:

| Приложение | Платформа | Как |
| --- | --- | --- |
| v2rayNG | Android | меню **+**, импорт из буфера обмена или сканирование QR-кода |
| Hiddify | Android, iOS, компьютер | добавить профиль из буфера обмена или по QR-коду |
| Streisand | iOS | добавить из буфера обмена или по QR-коду |
| SFA (sing-box for Android) | Android | добавить удалённый профиль с адресом подписки |

В браузере адрес подписки показывает
[[~subscription-page|страницу подписки]] пользователя с расходом и кнопками
импорта. Подробности — в [[use/subscriptions]].

::: warning Две вещи, похожие на нерабочую ссылку
- В v2rayNG и других приложениях на основе Xray **Mux** должен быть
  выключен. Если он включён, соединение молча не работает.
- v2rayNG обновляет только группу подписки, открытую на экране. Сначала
  выберите вкладку новой группы, потом обновляйте.
:::

## 6. Проверьте подключение {#_6-check-it-connects}

Подключитесь в приложении и откройте веб-страницу. В панели в строке
пользователя в течение минуты появится трафик, а в списке **Соединения**
узла — открытое соединение.

Если подключиться не удаётся, см. [[troubleshooting#users-cannot-connect]].
