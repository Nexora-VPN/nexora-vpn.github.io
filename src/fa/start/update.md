# به‌روزرسانی

[[~panel|پنل]] و [[~node|نودها]] جداگانه منتشر و به‌روز می‌شوند. **اول پنل را
به‌روز کنید، بعد نودها را.** ممکن است نود جدیدتر دیگر به درخواستی که پنل قدیمی‌تر
به آن متکی است جواب ندهد، مثل برداشتن یک حساب از روی نود در همان لحظه‌ای که
منقضی می‌شود.

## پنل، از صفحهٔ خودش {#the-panel-from-its-own-page}

پنل روزی یک بار نسخهٔ جدیدتر را بررسی می‌کند و اگر باشد یک بنر نشان می‌دهد.
**تنظیمات ← به‌روزرسانی پنل** نسخهٔ نصب‌شده، جدیدترین نسخه، روش نصب این پنل و
یادداشت‌های انتشار را نشان می‌دهد.

روی نصبی که با اسکریپت انجام شده، **همین حالا به‌روزرسانی کن** کل ارتقا را انجام
می‌دهد:

1. **گرفتن پشتیبان** از پایگاه داده در پوشهٔ پشتیبان‌هایتان.
2. **دانلود** نسخه.
3. **بررسی صحت** آن با checksum که همراهش منتشر شده، و یک بار اجرایش تا مطمئن
   شود روی این سرور بالا می‌آید.
4. **نصب** آن، با نگه داشتن باینری قبلی به نام
   `/opt/nexora-panel/nexora-panel.previous`.
5. **راه‌اندازی مجدد.** از حسابتان خارج نمی‌شوید. پنل چند ثانیه در دسترس نیست،
   و صفحه می‌گوید کی برگشته است.

اگر نسخهٔ تازه بالا نیاید، باینری قبلی در حدود ده ثانیه خودکار برگردانده می‌شود،
و صفحه **برگردانده شد** را نشان می‌دهد.

::: warning پایگاه داده برگردانده نمی‌شود
تغییرات پایگاه داده فقط رو به جلو است. اگر بعد از به‌روزرسانی چیزی درست به نظر
نمی‌رسد، راه برگشت پشتیبانی است که در قدم ۱ گرفته شده: آن را در **تنظیمات ←
پشتیبان‌گیری** بازیابی کنید ([[use/backup]] را ببینید).
:::

::: danger برگشت به نسخهٔ قدیمی‌تر
از نسخه‌ای که **تنظیمات ← آدرس‌ها** ([[use/ingress]]) را می‌آورد، پنل پورت‌ها،
دامنه‌ها، مسیرها و HTTPS خود را به شکلی تازه نگه می‌دارد و تنظیمات قدیمی از پایگاه
داده حذف می‌شوند. نسخهٔ قدیمی‌تری که روی آن پایگاه داده اجرا شود هیچ‌کدام را پیدا
نمی‌کند: روی پورت 2095، با HTTP ساده و بدون دامنه و مسیر بالا می‌آید.

- **پیش از به‌روزرسانی پشتیبان بگیرید و نگهش دارید.** **به‌روزرسانی** در قدم ۱
  یکی می‌گیرد؛ نصب‌کننده پایگاه دادهٔ SQLite را در `nexora.db.bak` کپی می‌کند.
- با نصب نسخهٔ قدیمی‌تر روی نسخهٔ تازه **برنگردید**.
- اگر به‌روزرسانی از این صفحه شکست بخورد و نسخهٔ قبلی خودش برگردانده شود، همین
  اتفاق می‌افتد. به‌روزرسانی را دوباره اجرا کنید، در صورت نیاز از روی سرور، یا
  پشتیبانِ پیش از به‌روزرسانی را با
  `nexora-panel restore FILE -keep-web-settings=false` بازیابی و پنل را ری‌استارت کنید.
:::

**بررسی روزانهٔ انتشار نسخهٔ جدید** بررسی روزانه را خاموش می‌کند. این بررسی
روزی یک درخواست به مخزن عمومی پنل است، که آدرس سرور شما را به آن نشان می‌دهد.
دکمه با بررسی خاموش هم کار می‌کند.

## پنل، از خط فرمان {#the-panel-from-the-command-line}

نصب‌کننده را دوباره اجرا کنید. نصب موجود را پیدا می‌کند و درجا به‌روزش می‌کند:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/nexora-vpn/panel/main/install.sh)
```

سرویس را متوقف می‌کند، پایگاه دادهٔ SQLite را در `nexora.db.bak` کپی می‌کند،
باینری قبلی را نگه می‌دارد، پایگاه داده را به‌روز می‌کند و دوباره اجرا می‌شود.
تنظیمات و حساب‌های مدیر شما دست نمی‌خورند. روی PostgreSQL، اول خودتان از پایگاه
داده dump بگیرید.

## پنل در Docker {#the-panel-in-docker}

کانتینر نمی‌تواند ایمیج خودش را عوض کند، و صفحهٔ به‌روزرسانی پنل هم همین را
می‌گوید. در پوشهٔ فایل compose:

```bash
docker compose pull && docker compose up -d
```

## نودها {#the-nodes}

بخش **نودها** در صفحهٔ **به‌روزرسانی پنل** جدیدترین نسخهٔ نود و تعداد نودهایی
را که از آن عقب‌اند نشان می‌دهد.

- **آپدیت همهٔ نودها** نودها را یکی‌یکی با SSH به‌روز می‌کند. نودی که پنل برایش
  کلید SSH مجاز ندارد رد می‌شود.
- **یک نود:** کشوی **نصب** آن را باز کنید، به **خودکار (SSH)** بروید و
  **به‌روزرسانی** را بزنید. پنل باینری تازه را بارگذاری می‌کند (یا ایمیج تازه را
  می‌کشد) و نود را دوباره راه‌اندازی می‌کند.
- **دستی:** دستور نصب نود را دوباره روی سرورش اجرا کنید. نصب موجود را پیدا
  می‌کند، پیکربندی و گواهی‌هایش را نگه می‌دارد و فقط باینری را عوض می‌کند.
- **نود در Docker:** `docker compose pull && docker compose up -d`.

به‌روزرسانی گواهی‌های نود را نگه می‌دارد، پس پنل همچنان آن را می‌شناسد و چیزی
نباید دوباره ثبت شود.

پنل باینری نودی را که نگه می‌دارد بارگذاری می‌کند (**دانلودشده روی این پنل**).
وقتی این نسخه از جدیدترین نسخهٔ نود قدیمی‌تر باشد، **دانلود آخرین نود** آن را
تازه می‌کند، و به‌روزرسانی نود در این فاصله جدیدترین نسخه را از GitHub می‌گیرد.

## در طول به‌روزرسانی {#during-an-update}

نود در زمان راه‌اندازی مجدد پنل به سرو کردن ادامه می‌دهد: به‌روزرسانی پنل اتصال
هیچ کس را قطع نمی‌کند. نودی که سه دقیقه به پنلش نرسد، تا برگشتن پنل سرو کردن را
متوقف می‌کند، پس پنل را مدت زیادی خاموش نگذارید.
