# خط فرمان

[[~panel|پنل]] و [[~node|نود]] هر کدام یک برنامه با چند دستورند. بیشتر روزها
هیچ‌وقت تایپشان نمی‌کنید: نصب‌کننده‌ها و صفحه‌های پنل کار را انجام می‌دهند. به
آن‌ها وقتی نیاز دارید که بخواهید پنلی را که به آن نمی‌رسید برگردانید، وقتی پنل
بالا نمی‌آید پشتیبانی را بازیابی کنید، یا یک نصب را اسکریپت کنید.

نصب‌کنندهٔ پنل `nexora-panel` را در PATH قرار می‌دهد، و این برنامه فایل
پیکربندی خودش را پیدا می‌کند، پس همهٔ دستورها از هر پوشه‌ای کار می‌کنند. در
Docker، `docker compose exec panel /app/` را جلوی دستور بگذارید:
`docker compose exec panel /app/nexora-panel config list`.

## nexora-panel {#nexora-panel}

| دستور | چه می‌کند |
| --- | --- |
| `run [-config FILE] [-listen IP:PORT]` | پنل را اجرا می‌کند. سرویس این کار را برایتان انجام می‌دهد |
| `migrate [-config FILE] [-user U -pass P]` | جدول‌های پایگاه داده را می‌سازد یا به‌روز می‌کند. با `-user` و `-pass` یک مدیر اصلی هم می‌سازد، برای نصبی که مرورگر ندارد؛ بدون آن‌ها پنل ویزارد راه‌اندازی‌اش را باز می‌کند |
| `config list` | تنظیمات سراسری پنل را نشان می‌دهد |
| `config get KEY` | یک تنظیم را می‌خواند |
| `config set KEY VALUE` | یک تنظیم را می‌نویسد. `""` آن را پاک می‌کند. بیشترشان با راه‌اندازی مجدد پنل اعمال می‌شوند |
| `setup-token [-rotate]` | توکن یک‌بارمصرف ویزارد راه‌اندازی را چاپ می‌کند، یا آن را با توکن تازه‌ای عوض می‌کند |
| `admin list` | حساب‌های مدیر را فهرست می‌کند و مالک پنل را علامت می‌زند |
| `admin reset-password [-user U] [-pass P]` | گذرواژهٔ یک مدیر را تعیین می‌کند |
| `restore FILE [-passphrase P] [-yes]` | پایگاه داده را با یک فایل پشتیبان جایگزین می‌کند |
| `hwid` | **شناسهٔ سخت‌افزار (HWID)** را که صفحهٔ **لایسنس** نشان می‌دهد چاپ می‌کند |
| `version` | نسخهٔ پنل را چاپ می‌کند |
| `help` | دستورها را نشان می‌دهد |

`-config FILE` یک دستور را به فایل پیکربندی دیگری می‌فرستد. دستورهایی که پایگاه
داده را باز می‌کنند آن را بعد از آرگومان‌های دیگرشان می‌پذیرند، مثلاً
`nexora-panel config list -config /path/to/config.json`.

### تنظیمات از خط فرمان {#settings-from-the-command-line}

`config` تنظیماتی را می‌خواند و می‌نویسد که فقط مدیر اصلی اجازهٔ تغییرشان را
دارد: آدرس، دامنه، مسیر و گواهی پنل، دامنه‌ها و مسیر اشتراک، پشتیبان‌گیری،
پراکسی‌های مورد اعتماد و فهرست مجاز ورود، و چند مورد دیگر. `config list` همه را
نشان می‌دهد.

مقدار محرمانه، مثل عبارت عبور پشتیبان، فقط به صورت `(set)` نشان داده می‌شود.
`config set` کلیدی را که تنظیم پنل نیست و مقداری را که پنل نمی‌پذیرد رد می‌کند.
تنظیمات پشتیبان‌گیری در کمتر از یک ساعت و بدون راه‌اندازی مجدد اعمال می‌شوند؛
برای بقیه پنل را دوباره راه‌اندازی کنید (`systemctl restart nexora-panel`).

### restore {#restore}

```bash
systemctl stop nexora-panel
nexora-panel restore /var/opt/nexora/backups/nexora-backup-20260914-030000.tar.gz
systemctl start nexora-panel
```

اول فایل را می‌خواند، محتوا و هر هشداری را چاپ می‌کند، و از شما می‌خواهد
`replace-database` را تایپ کنید. در اسکریپت، به جای آن `-yes` بدهید. فایل
رمزگذاری‌شده `-passphrase` را می‌پذیرد یا آن را می‌پرسد.

مثل پنل، تنظیمات آدرس و لایسنس خود این سرور نگه داشته می‌شوند.
`-keep-web-settings=false` و `-keep-license=false` به جای آن‌ها مقدارهای فایل
پشتیبان را می‌گیرند. پیش از هر تغییری، یک نسخه از پایگاه دادهٔ فعلی نوشته
می‌شود.

اول پنل را متوقف کنید. روی SQLite جایگزینی در اجرای بعدی پنل انجام می‌شود، پس
هر چه پنل در حال اجرا در این فاصله بنویسد از دست می‌رود؛ روی PostgreSQL ردیف‌ها
فوراً و زیر پای پنل جایگزین می‌شوند.

## بیرون مانده‌اید {#locked-out}

هر تنظیمی که می‌تواند پنل را از دسترس خارج کند، بدون اجرای پنل از خط فرمان قابل
تغییر است:

```bash
nexora-panel config list                       # what is set
nexora-panel config set web_listen_port 2095   # a port you can reach
nexora-panel config set web_listen_ip ""       # listen everywhere again (IPv4 and IPv6)
nexora-panel config set web_domain ""          # stop restricting the hostname
nexora-panel config set web_basepath ""        # serve at the root again
nexora-panel config set sub_domain ""          # stop reserving hosts for subscriptions
systemctl restart nexora-panel
```

مورد آخر وقتی پنل **مسیر پایه ندارد** غافلگیرتان می‌کند. دامنه‌ای که در
`sub_domain` است فقط اشتراک‌ها را سرو می‌کند و هیچ چیز دیگری را، پس وقتی پنل در
ریشه است، آن نام‌ها هرگز پنل را نشان نمی‌دهند. اگر فقط از همین نام‌ها استفاده
می‌کنید، پنل همه جا از دسترس خارج است. مسیر پایه این دام را برمی‌دارد: پنل زیر
آن مسیر روی همهٔ نام‌ها در دسترس می‌ماند.

در Docker، پورت در فایل compose تعیین می‌شود، نه با `config set`.

### گذرواژهٔ فراموش‌شده {#forgotten-password}

```bash
nexora-panel admin list                        # the accounts, and which one owns the panel
nexora-panel admin reset-password              # the owner; the password is typed, not shown
nexora-panel admin reset-password -user alice  # any other account
```

بدون `-user`، گذرواژهٔ **مالک** پنل بازنشانی می‌شود. گذرواژهٔ تازه دو بار پرسیده
می‌شود و هیچ‌وقت نمایش داده نمی‌شود. `-pass` آن را یک‌جا تعیین می‌کند، اما در
تاریخچهٔ شل شما باقی می‌گذارد.

بازنشانی همچنین **ورود دومرحله‌ای را خاموش می‌کند** تا حساب بتواند دوباره از پنل
ثبت‌نام کند، و **همهٔ نشست‌های باز** آن حساب را **پایان می‌دهد**. پنل در حال اجرا
ممکن است تا یک دقیقه از فعالیت، یک نشست کش‌شده را بپذیرد؛ اگر مهم است، پنل را
دوباره راه‌اندازی کنید.

### بیرون مانده به خاطر مسدودی {#locked-out-by-a-ban}

پنج ورود ناموفق از یک آدرس آن را مسدود می‌کند، و مسدودی بعد از راه‌اندازی مجدد
هم می‌ماند. دو تنظیم تعیین می‌کنند آن آدرس کیست و چه کسی هرگز مسدود نمی‌شود:

```bash
nexora-panel config set trusted_proxies "10.0.0.0/8"   # your reverse proxy or CDN, or empty
nexora-panel config set login_allowlist "203.0.113.7"  # addresses never banned
```

::: warning پشت پراکسی یا CDN
بدون `trusted_proxies`، پنلی که پشت یک reverse proxy یا CDN است هر بازدیدکننده
را با آدرس پراکسی می‌بیند، پس اولین مسدودی همه را بیرون می‌گذارد. آن را روی
آدرس‌های پراکسی تنظیم کنید، و آدرس خودتان را در `login_allowlist` نگه دارید.
:::

وقتی دوباره وارد شدید، مدیر اصلی می‌تواند مسدودی را در **تنظیمات ← امنیت**
بردارد ([[use/security]]).

## nexora-node {#nexora-node}

نود را پنل نصب و پیکربندی می‌کند، پس دستورهایش کم‌اند:

| دستور | چه می‌کند |
| --- | --- |
| `run [-config FILE]` | نود را اجرا می‌کند. سرویس این کار را برایتان انجام می‌دهد |
| `gencerts [-dir DIR]` | گواهی و کلید خود نود را برای نصب دستی می‌سازد |
| `version` | نسخهٔ نود را چاپ می‌کند |
| `help` | دستورها را نشان می‌دهد |

نصب‌کنندهٔ نود اسکریپت جداگانه‌ای است که پنل شما سرو می‌کند؛ گزینه‌هایش در
[[add-node#install-options]] آمده است.
