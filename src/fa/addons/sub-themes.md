# ساختن تم صفحهٔ اشتراک

این صفحه برای کسی است که می‌خواهد کاربرانش وقتی آدرس اشتراکشان را در مرورگر باز
می‌کنند طراحی خود او را ببینند. تم [[~subscription-page|صفحهٔ اشتراک]] را برای
همهٔ کاربران پنل عوض می‌کند. تم یک فایل HTML است، با هر تصویر و استایلی که کنارش
باشد، که پنل آن را با داده‌های کاربر پر می‌کند. انتخاب تم و دیگر تنظیمات صفحه در
[[use/subscriptions#the-subscription-page]] آمده است.

## تم چیست {#what-a-theme-is}

تم یک پوشه در فولدر تم‌های پنل است:

```
sub-themes/
└── aurora/
    ├── index.html     the page (or sub.html)
    ├── style.css
    └── logo.svg
```

- `index.html` یک [Go `html/template`](https://pkg.go.dev/html/template) است:
  HTML معمولی با جای‌نگهدارهای `{{ … }}` که پنل در هر بازدید پرشان می‌کند. پنل
  هر مقدار را برای جایی که در آن قرار می‌گیرد escape می‌کند، پس یادداشت یک کاربر
  نمی‌تواند markup به صفحه اضافه کند.
- فایل‌های دیگر پوشه در `{{ .AssetBase }}/<name>` سرو می‌شوند:
  `<link rel="stylesheet" href="{{ .AssetBase }}/style.css">`. فایل‌هایی که
  نامشان با نقطه شروع می‌شود هرگز سرو نمی‌شوند.
- نام پوشه نام تم در پنل است: حرف، رقم، `.`، `_` و `-`، تا ۶۴ نویسه.
- یک `<title>` ثابت نام تم را در فهرست انتخاب پنل تعیین می‌کند. اگر عنوان
  جای‌نگهدار داشته باشد، فهرست انتخاب نام پوشه را نشان می‌دهد.
- مرحلهٔ build ندارد. پنل چند ثانیه پس از هر ویرایش فایل را دوباره می‌خواند،
  بدون ری‌استارت.
- تمی که بارگذاری یا ساخته نشود به صفحهٔ داخلی بنفش برمی‌گردد، پس یک اشتباه هرگز
  اشتراک کاربری را از کار نمی‌اندازد. لاگ پنل می‌گوید چه چیزی خراب شد.

تم فقط می‌تواند چیزی را که پنل به آن می‌دهد قالب‌بندی کند. به دیتابیس، دیسک یا
شبکه دسترسی ندارد.

## از تم آغازین شروع کنید {#start-from-the-starter}

مخزن عمومی
[`github.com/nx-panel/sub-themes`](https://github.com/nx-panel/sub-themes)،
با مجوز MIT، این‌ها را دارد:

| پوشه | چیست |
| --- | --- |
| `starter/` | کوچک‌ترین صفحهٔ کامل، با توضیح‌هایی برای کپی کردن: وضعیت، مصرف، انقضا، QR کد، دکمه‌های اپ، هر پیکربندی، فایل‌های پیکربندی، اطلاعیه‌ها و به‌روزرسانی زنده. یک فایل HTML و یک فایل استایل. |
| `builtin/violet/`، `builtin/amber/` | دو صفحهٔ خود پنل. بزرگ‌ترند و برای برداشتن تکه‌ها مناسب‌اند: زبانه‌ها، حلقهٔ مصرف، نمودار تاریخچهٔ ترافیک. |
| `check/` | `go run ./check` هر تم را همان‌طور که پنل تجزیه می‌کند تجزیه می‌کند. |

1. `starter/` را در پوشه‌ای با نام تم خودتان کپی کنید.
2. آن را روی یک پنل بگذارید (پایین‌تر) و صفحهٔ یک کاربر را باز کنید.
3. HTML و فایل استایل را تغییر دهید. هر بخشی را که نمی‌خواهید حذف کنید: بخش‌ها به
   هم وابسته نیستند.
4. پیش از نصب یا به اشتراک گذاشتن تم، `go run ./check` را در مخزن اجرا کنید.

## نصب و پیش‌نمایش {#install-and-preview}

1. پوشهٔ تم را در فولدر تم‌ها روی سرور پنل کپی کنید: در نصب استاندارد
   `/var/opt/nx-panel/sub-themes/`، و در Docker `./sub-themes/` کنار فایل
   compose. مدیر اصلی می‌تواند **فولدر تم‌ها** را جای دیگری بگذارد.
2. در **تنظیمات ← اشتراک‌ها ← صفحه اشتراک** روی
   **پویش دوباره فولدر تم‌ها** بزنید و تم را زیر **تم** انتخاب کنید.
3. آدرس اشتراک یک کاربر را با `/page` در انتها باز کنید، مثل
   `https://sub.example.com/sub/<token>/page`. این آدرس همیشه صفحه را نشان
   می‌دهد، حتی به یک اپ.
4. برای دیدن صفحه به زبانی دیگر `?lang=fa` (یا `en`، `ru`، `zh`) اضافه کنید.

برای امتحان یک تم بدون اینکه همهٔ کاربران به آن بروند، آن تم را به یک برندینگ
بدهید و برندینگ را به یک [[~reseller|نمایندهٔ]] آزمایشی یا به یک مسیر روی یک هاست
آزمایشی وصل کنید ([[use/ingress#brandings]]). فقط اشتراک‌هایی که آن برندینگ را
می‌گیرند آن را می‌بینند.

## داده‌هایی که تم می‌گیرد {#the-data-a-theme-receives}

صفحه از یک مقدار پر می‌شود که در قالب به شکل `.` نوشته می‌شود. فیلدها با نام‌های
زیر خوانده می‌شوند: `{{ .User.Name }}`، `{{ .Usage.UsedText }}`. درون یک
`{{ range }}`، `.` همان آیتم است؛ با `$` به مقدار صفحه برسید، مثل
`{{ index $.T "copy" }}`.

### حساب: `.User` {#the-account-user}

| فیلد | |
| --- | --- |
| `.Name`، `.Remark`، `.Desc`، `.Group` | نام، یادداشت، توضیح و برچسب حساب |
| `.SubID` | توکن اشتراک |
| `.Enable` | اینکه حساب روشن است یا نه |
| `.Online` | ترافیک در ۹۰ ثانیهٔ اخیر |
| `.OnlineAt` | ثانیهٔ یونیکس آخرین ترافیک؛ `0` یعنی هرگز |
| `.Status` | یک کلمه: `active`، `disabled`، `pending`، `expired` یا `limited`. `disabled` بر بقیه مقدم است؛ `pending` پلنی است که با اولین اتصال شروع می‌شود و هنوز شروع نشده |

### ترافیک: `.Usage` {#traffic-usage}

| فیلد | |
| --- | --- |
| `.Up`، `.Down`، `.Used` | بایت‌ها در دورهٔ فعلی |
| `.Total` | سهمیه به بایت؛ بدون سقف `0` |
| `.Remaining` | بایت‌های مانده |
| `.Percent` | `0` تا `100`؛ بدون سقف `0` |
| `.Unlimited` | بدون سقف ترافیک |
| `.UsedText`، `.TotalText`، `.RemainingText` | همین‌ها، نوشته‌شده برای خواندن، مثل `2.0 GB`. `.RemainingText` بدون سقف `∞` است |
| `.TotalUp`، `.TotalDown`، `.Lifetime`، `.LifetimeText` | مجموع‌هایی که با ریست دوره‌ای پاک نمی‌شوند |

### انقضا و ریست: `.Expire`، `.Reset` {#expiry-and-reset-expire-reset}

| فیلد | |
| --- | --- |
| `.Expire.At` | ثانیهٔ یونیکس؛ `0` یعنی هرگز |
| `.Expire.Never`، `.Expire.Expired` | بدون انقضا؛ از قبل منقضی شده |
| `.Expire.Days` | روزهای مانده، رو به بالا گرد شده؛ پس از انقضا `0` |
| `.Expire.Pending` | پلن با اولین اتصال شروع می‌شود و هنوز شروع نشده |
| `.Expire.Duration` | طول پلن به ثانیه؛ برای تاریخ ثابت `0` |
| `.Reset.Auto`، `.Reset.Days`، `.Reset.Next` | ریست دوره‌ای ترافیک: روشن یا خاموش، هر چند روز یک بار، و ریست بعدی به ثانیهٔ یونیکس |

::: warning پیش از نوشتن تاریخ، `.Expire.Pending` را بررسی کنید
پلنی که با اولین اتصال شروع می‌شود تاریخی موقت دارد که وقتی کاربر وصل می‌شود
جابه‌جا می‌شود. در این حالت `.Expire.Days` کل پلن است. چیزی مثل «۳۰ روز، از اولین
اتصال شما» بنویسید، همان‌طور که تم آغازین می‌نویسد.
:::

### راه‌های اتصال: `.Configs`، `.Links`، `.Apps` {#ways-to-connect-configs-links-apps}

`.Configs` برای هر اتصالی که کاربر دارد یک ورودی است:

| فیلد | |
| --- | --- |
| `.Name` | نام ورودی، همان‌طور که اپ‌ها نشانش می‌دهند |
| `.Protocol`، `.Network`، `.Security` | مثل `vless`، `ws`، و `reality`، `tls` یا `none` |
| `.Address` | سرور و پورت، آمادهٔ نمایش: `203.0.113.10:443`، `[2001:db8::1]:443` |
| `.Server`، `.Port` | همین، جدا از هم |
| `.Link` | لینک اشتراک‌گذاری |

`.Address` را نشان دهید. اگر خودتان `{{ .Server }}:{{ .Port }}` بنویسید، سرور
IPv6 به `2001:db8::1:443` تبدیل می‌شود که نه آدرس درستی خوانده می‌شود و نه پورت
درستی.

`.Links` همان لینک‌های اشتراک‌گذاری است، به شکل یک فهرست ساده.

`.Apps` فایل‌های پیکربندی کاربران WireGuard، OpenVPN و OpenConnect است:
`.Name`، `.Type`، `.FileName` و `.Content`، یعنی کل فایل. یک QR کد، یک دانلود و
یک دکمهٔ کپی بگذارید:

```html
{{ range .Apps }}
  {{ $code := qr .Content }}
  {{ if $code }}{{ $code }}{{ else }}<p>{{ index $.T "qrTooBig" }}</p>{{ end }}
  <a download="{{ .FileName }}" href="{{ dataURI "text/plain" .Content }}">{{ index $.T "download" }}</a>
  <button data-copy="{{ .Content }}">{{ index $.T "copy" }}</button>
{{ end }}
```

### اشتراک: `.Sub` {#the-subscription-sub}

| فیلد | |
| --- | --- |
| `.URL` | آدرس اشتراک کاربر |
| `.URLs` | آدرس هر فرمت، که به شکل `{{ index .Sub.URLs "clash" }}` خوانده می‌شود: `clash` همان `<subscription>/clash` است، `singbox` همان `/singbox`، `xray` همان `/xray`، `plain` همان `/plain`، و `v2ray` خود آدرس است |
| `.UpdateInterval` | به اپ‌ها گفته می‌شود میان دو به‌روزرسانی چند ساعت صبر کنند |
| `.Incy`، `.V2RayTun` | لینک‌های آمادهٔ وارد کردن برای INCY و V2RayTun، که وقتی کلید اپ را ذخیره کنید رمزشده‌اند ([[use/subscriptions#encrypted-import-links]]). هر کدام را به‌عنوان کل یک `href` به کار ببرید |

### تاریخچهٔ ترافیک: `.Chart` {#the-traffic-history-chart}

ترافیک کاربر، از پیش به شکل ستون چیده شده، تا صفحه آن را بدون اسکریپت بکشد.

- وقتی پنل تاریخچهٔ ترافیک نگه نمی‌دارد، `.Chart.Recording` برابر false است. در
  این حالت چیزی نکشید.
- `.Chart.Ranges` بازه‌ها به ترتیب است: ۲۴ ستون ساعتی، بعد ۷ و ۱۴ ستون روزانه.
  هر کدام `.Key`، `.LabelKey` (عبارتی در `.T`)، `.Default` (آنکه اول نشان داده
  می‌شود)، `.Width`، `.Empty`، `.MaxText`، `.TotalText` و `.Points` دارد.
- هر نقطه یک ستون است: `.At`، `.Label`، `.Up`، `.Down`، `.Text`، و جایگاهش
  `.X`، `.W`، `.DownY`، `.DownH`، `.UpY`، `.UpH`.

```html
{{ range .Chart.Ranges }}{{ if .Default }}
<svg viewBox="0 0 {{ .Width }} {{ $.Chart.Height }}" preserveAspectRatio="none">
  {{ range .Points }}
  <rect x="{{ .X }}" y="{{ .DownY }}" width="{{ .W }}" height="{{ .DownH }}" fill="#6d4aff"/>
  <rect x="{{ .X }}" y="{{ .UpY }}" width="{{ .W }}" height="{{ .UpH }}" fill="#b9a8ff"/>
  {{ end }}
</svg>
{{ end }}{{ end }}
```

ستون‌ها از نیمه‌شب و سر ساعت به وقت محلی پنل شروع می‌شوند. ترافیکی را نشان
می‌دهند که واقعاً از سیم گذشته، و روی نودی با ضریب ترافیک، یا بعد از ریست،
می‌تواند با `.Usage` فرق داشته باشد. صفحه‌های داخلی با دکمه‌های رادیویی و بدون
اسکریپت بین بازه‌ها جابه‌جا می‌شوند.

### تنظیمات شما و بقیه {#your-settings-and-the-rest}

| فیلد | |
| --- | --- |
| `.Panel.Title`، `.Panel.SupportURL`، `.Panel.Announce` | **عنوان پروفایل**، **لینک پشتیبانی** و **اعلان** |
| `.Panel.Version` | نسخهٔ پنل |
| `.Notices` | هشدارهای کوتاه برای کاربران، از پیش ترجمه‌شده، هر کدام با یک `.Key` ثابت و `.Text` خودش. روی آن‌ها range بزنید، تا اطلاعیه‌ای که بعداً اضافه شود بدون هیچ تغییری در تم شما نشان داده شود |
| `.Lang`، `.Dir` | زبان صفحه (`en`، `fa`، `ru`، `zh`) و جهتش (`ltr`، `rtl`) |
| `.T` | عبارت‌های صفحهٔ داخلی به همان زبان: `{{ index .T "copy" }}` |
| `.AssetBase` | جایی که فایل‌های خود تم سرو می‌شوند |
| `.Now`، `.Timezone` | زمان بازدید، به ثانیهٔ یونیکس، و منطقهٔ زمانی پنل |

## توابع کمکی {#helper-functions}

| تابع | مثال |
| --- | --- |
| `bytes` | `{{ bytes .Usage.Up }}` ← `2.0 GB` |
| `date`، `datetime` | `{{ date .Expire.At }}` ← `2026-11-03` |
| `when` | `{{ when .User.OnlineAt .T }}` ← `Today 09:30` |
| `num` | `{{ num .Expire.Days }}` ← `40` |
| `qr` | `{{ qr .Sub.URL }}` ← یک QR کد به شکل SVG درون‌خطی، یا هیچ، برای متنی که برای یک QR کد زیادی بلند است |
| `dataURI` | `href="{{ dataURI "text/plain" .Content }}"` برای دانلود |
| `b64` | `{{ b64 .Sub.URL }}` ← base64 |
| `default` | `{{ default "Subscription" .Panel.Title }}` |
| `hasPrefix` | `{{ if hasPrefix "vless" .Protocol }}…{{ end }}` |
| `json` | `<script>var configs = {{ json .Configs }}</script>` |
| `urlquery` | یک مقدار را percent-encode می‌کند، برای آدرسی که درون یک اسکریپت ساخته می‌شود |

روی صفحهٔ فارسی، `date`، `datetime` و `when` تاریخ هجری شمسی می‌نویسند، و این‌ها
همراه با `bytes` و `num` رقم فارسی می‌نویسند: `{{ date .Expire.At }}` نتیجهٔ
`۱۴۰۵/۰۸/۱۲` را می‌دهد. هر عددی را که خودتان چاپ می‌کنید از `num` بگذرانید، و
هرگز آدرس، پورت یا لینک را. دو عدد را با `{{ index .T "sep" }}` کنار هم بگذارید،
که در بیشتر زبان‌ها ` · ` و در فارسی `، ` است.

نتیجهٔ `qr` را همیشه در یک متغیر نگه دارید و بررسی‌اش کنید، همان‌طور که مثال
`.Apps` در بالا می‌کند. فایل پیکربندی بلند QR کد ندارد، و `qr` بررسی‌نشده جای
خالی به جا می‌گذارد.

## دکمه‌هایی که اشتراک را به اپ اضافه می‌کنند {#buttons-that-add-the-subscription-to-an-app}

هر اپ نوع لینک خودش را باز می‌کند:

| اپ | `href` | آدرس کجا می‌آید |
| --- | --- | --- |
| Happ | `happ://add/{{ .Sub.URL }}` | در مسیر |
| V2RayTun | `{{ .Sub.V2RayTun }}` | کل لینک |
| INCY | `{{ .Sub.Incy }}` | کل لینک |
| Streisand | `streisand://import/{{ .Sub.URL }}` | در مسیر |
| Hiddify | `hiddify://import/{{ .Sub.URL }}` | در مسیر |
| Shadowrocket | `shadowrocket://add/sub://{{ b64 .Sub.URL }}` | base64، در مسیر |
| v2rayNG | `v2rayng://install-sub?url={{ .Sub.URL }}` | در query |
| V2Box | `v2box://install-sub?url={{ .Sub.URL }}&name={{ .Panel.Title }}` | در query |
| NekoBox | `sn://subscription?url={{ .Sub.URL }}&name={{ .Panel.Title }}` | در query |
| اپ‌های sing-box (SFA، SFI) | `sing-box://import-remote-profile?url={{ index .Sub.URLs "singbox" }}` | فرمت خودش، در query |
| اپ‌های Clash (Clash Meta، mihomo) | `clash://install-config?url={{ index .Sub.URLs "clash" }}` | فرمت خودش، در query |

مقدار بعد از `?url=` را همان‌طور که هست بنویسید. قالب خودش آن را کدگذاری می‌کند،
و کدگذاری دوباره با `urlquery` آدرسی می‌سازد که هیچ اپی نمی‌تواند بخواند. اپ‌های
Clash و sing-box آدرس فرمت خودشان را می‌گیرند، پس وارد کردن کار می‌کند، چه پنل
اپ را بشناسد چه نه.

## مصرف را زنده نگه دارید {#keep-usage-live}

صفحه یک بار، هنگام باز شدن، کشیده می‌شود. برای اینکه مصرف و نقطهٔ آنلاین به‌روز
بمانند، همین داده‌ها را به شکل JSON بگیرید:

| آدرس | پاسخ |
| --- | --- |
| `<subscription>/info` | همهٔ موارد بالا به شکل JSON، با نام‌هایی که با حرف کوچک شروع می‌شوند (`usage.usedText`، `user.online`). لینک‌های اشتراک‌گذاری، محتوای فایل‌های پیکربندی و نمودار در آن نیستند |
| `<subscription>/info?chart=1` | همان، با نمودار |

```html
<span data-info="usage.usedText">{{ num .Usage.UsedText }}</span>
<script>
  var INFO = {{ .Sub.URL }} + "/info";
  setInterval(function () {
    fetch(INFO, { cache: "no-store" }).then(function (r) { return r.json() }).then(function (info) {
      document.querySelectorAll("[data-info]").forEach(function (el) {
        el.textContent = el.dataset.info.split(".").reduce(function (v, k) { return v && v[k] }, info)
      })
    })
  }, 30000)
</script>
```

مقداری که درون یک `<script>` چاپ شود خودکار به شکل رشتهٔ JavaScript نوشته
می‌شود. عددهای JSON با رقم لاتین می‌آیند: تم آغازین نشان می‌دهد چطور روی صفحهٔ
فارسی آن‌ها را به رقم فارسی تبدیل کنید. بیشتر از هر ۳۰ ثانیه یک بار درخواست
نفرستید، و نمودار را فقط وقتی بخواهید که دوباره می‌کشیدش.

## زبان‌ها و راست‌به‌چپ {#languages-and-right-to-left}

زبان صفحه از `?lang=` در آدرس می‌آید، وگرنه از مرورگر، وگرنه انگلیسی است.

- `lang="{{ .Lang }}" dir="{{ .Dir }}"` را روی `<html>` بگذارید. صفحه‌های فارسی
  راست‌به‌چپ‌اند.
- فایل استایل را با ویژگی‌های منطقی (`margin-inline-start`،
  `border-inline-start`، `text-align: start`) بنویسید تا یک دسته قاعده هر دو جهت
  را بچیند.
- برای کلمه‌ها از `.T` استفاده کنید، یا کلمه‌های خودتان را برای هر چهار زبان
  همراه تم بیاورید. کلمه‌ای که در یک زبان نباشد عنصری خالی به جا می‌گذارد.

## قاعده‌هایی که ارزش رعایت دارند {#rules-worth-keeping}

- **هیچ چیزی را از هاست دیگری بارگذاری نکنید.** کاربران این صفحه را پیش از وصل
  شدن VPN خود باز می‌کنند، اغلب روی شبکه‌ای که CDNهای فونت و اسکریپت را مسدود
  می‌کند. تمی که منتظر یکی از آن‌ها بماند صفحهٔ خالی نشان می‌دهد. فونت‌ها و
  تصویرها را در پوشهٔ تم بگذارید، یا از فونت‌های سیستم استفاده کنید.
- پیش از چاپ `qr`، آن را بررسی کنید.
- پیش از چاپ تاریخ، `.Expire.Pending` را بررسی کنید.
- `.Address` را نشان دهید، هرگز `.Server` و `.Port` را که دستی کنار هم گذاشته
  شده‌اند.
- به‌جای اینکه متن اطلاعیه‌ها را خودتان بنویسید، روی `.Notices` range بزنید.

به شکل یک پوشهٔ تازه در بالاترین سطح مخزن و یک `README.md` کوتاه با یک
اسکرین‌شات. README مخزن می‌گوید تمی که آنجاست باید چه کارهایی بکند. هر تمی که
آنجاست مجوز MIT دارد، پس اپراتورها می‌توانند آن را برای سرویس خودشان تغییر دهند.
