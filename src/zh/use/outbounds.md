# 出站

[[~outbound|出站]]是流量到达节点后的出口：直连互联网、拦截，或继续转发到另一台代理服务器。[[routing|路由]]为每个连接选择出站。出站放在**核心配置 → 出站**下的共享池中，通过[[templates|模板]]到达节点。

<NxShot page="outbounds" alt="出站页面：顶部统计条统计模板中和未使用的出站，下方是标签、类型和服务器的列表" />

## 何时需要出站 {#when-you-need-one}

每个节点都有一个名为 `direct` 的内置出站；没有路由规则时，所有流量都经它直接到达目标。大多数集群需要的就是这样。当流量应该去别处时，才需要添加出站：

- **拦截**某些内容：广告、BT 下载、一组目标地址。
- **链式转发**到另一台服务器：把部分或全部流量转发给上游代理，让互联网看到那台服务器的地址。
- 在多个上游之间**选择**：手动选择，或按测得的延迟选择。

## 类型 {#types}

| 类型 | 作用 |
| --- | --- |
| `direct` | 从节点直接连接目标。 |
| `block` | 拒绝连接。 |
| `socks`、`http` | 转发到 SOCKS 或 HTTP 代理。 |
| `shadowsocks`、`vmess`、`vless`、`trojan` | 转发到使用该协议的另一台代理服务器，带有自己的传输和 TLS。 |
| `hysteria`、`hysteria2`、`tuic` | 通过 QUIC 转发到使用该协议的服务器。 |
| `shadowtls`、`anytls`、`ssh`、`naive`、`mieru`、`snell`、`sudoku`、`trusttunnel`、`masque`、`tor` | 其他上游类型，供已经运行此类服务器的运营者使用。 |
| `selector` | 一组其他出站；由你选择使用其中一个。 |
| `urltest` | 一组其他出站；使用测得延迟最低的那个。 |

对于代理上游，在 **Basic** 和 **Protocol** 中填写服务器地址、端口和凭据，在对应标签页中填写其传输和 TLS。TLS 标签页按远端服务器的要求提供**无**、**TLS** 或 **REALITY**。

`selector` 或 `urltest` 列出它从中选择的出站的标签。这些出站必须在同一个模板中。

## 添加出站 {#adding-an-outbound}

1. 打开**核心配置 → 出站**，点击**添加**。
2. 选择 **Type** 并填写 **Tag**。路由通过标签引用出站，创建后不能修改。
3. 填写该类型显示的各个标签页。
4. 点击**保存**。
5. 在某个模板的**出站**中选中它，并在路由规则中或作为**默认出站**引用它。

没有被任何模板选中的出站不起作用。统计条将它们计入**未使用**。

## 路由如何引用出站 {#how-routing-names-an-outbound}

路由在四个地方通过标签引用出站：

- 路由规则的**出站**；
- 模板的**默认出站**，接收所有未被任何规则匹配的连接；
- 经由它拨号的另一个出站（detour）；
- 列出它的 `selector` 或 `urltest`。

**拦截 BT 下载**路由预设会添加一个自己的 `block` 出站，名为 `block-torrent`，由节点计数。见 [[routing#presets]]。

## 检查出站 {#checking-an-outbound}

节点行或用户行菜单中的**路由测试**会针对你描述的连接，逐条走一遍节点的路由规则，并给出接收该连接的出站。**测试并连接**还会从节点沿这条路径真正建立一次连接，报告是否到达目标以及耗时多久。经由代理上游时，结果可能是“未被拒绝，未确认”，因为代理并不总会告知其远端是否已连上。见 [[nodes]]。

只添加到某一个节点的出站（在节点的**配置**面板中）各有一个**测试**按钮，用于测量从该节点经由它的延迟。

## 单节点出站 {#per-node-outbounds}

节点可以在模板之外携带自己的出站，位于其**配置**面板的**本节点额外出站**中。当某台服务器需要其他服务器不需要的上游时使用，例如为某个地区提供不同的出口。

## 编辑和删除 {#editing-and-deleting}

编辑出站会把修改发送到携带它的每个节点。**创建副本**操作会以新标签复制一个出站。

只要还有内容通过标签引用某个出站，面板就会拒绝删除它：路由规则、模板的默认出站、detour 或分组。面板会列出这些引用。把它们改为指向别处后再删除。节点也会拒绝删除其正在运行的路由仍需要的出站，因此移除出站和引用它的规则这类修改应一起保存。
