# 分组与批量操作

用户页面可以一次处理多个账户：你勾选的行，或页面当前筛选出的所有账户。本页介绍分组、启动批量操作的两个菜单、每种操作的作用，以及面板拒绝修改的情况和原因。

<NxShot page="users" alt="勾选了多行的用户页面，添加按钮旁的批量操作菜单已打开" />

## 分组 {#groups}

分组是账户上的一个自由文本标签，在用户表单的**分组**字段中填写。它没有设置项，也没有自己的页面。它的作用是让你找出一组账户并一起处理。

- 在**筛选 → 分组**中选择一个分组，或点击列表中某个分组标签，即可只显示该分组的账户。
- [[~plan|套餐]]会把它的分组写入它创建的每个账户。由于套餐不会在账户上留下其他痕迹，日后要找出“所有买了 30 天套餐的人”，就靠分组。
- 批量创建可以给每个新账户设置同一个分组（见下文）。

## 两个菜单 {#the-two-menus}

**勾选行后**，**添加**旁会出现批量操作按钮。它的操作只作用于所勾选的账户。

**添加**旁的 **⋯ 按钮（操作）**作用于当前筛选出的整个列表，包括所有分页结果；没有设置筛选时，作用于所有账户。每个菜单项都标明“当前筛选”，它打开的对话框会在你确认之前说明将影响多少个账户。

| 操作 | 勾选的行 | 操作菜单 |
| --- | --- | --- |
| 启用、停用 | **启用**、**停用** | |
| 重置已用流量 | **重置流量** | **重置当前筛选的流量…** |
| 遗忘已登记的设备 | **重置设备** | |
| 增加天数或流量 | **续期与赠送** | **为当前筛选续期与赠送…** |
| 设置限额 | **设置限额** | |
| 移交给其他归属 | **更改归属** | |
| 导出 CSV 列表 | **下载 CSV** | **下载当前筛选的 CSV** |
| 导出配置 | **下载配置包** | |
| 删除 | **删除** | **删除过期用户…** |
| 创建多个账户 | | **批量创建用户…** |

## 每种操作的作用 {#what-each-operation-does}

### 启用和停用 {#enable-and-disable}

**停用**会关闭账户，并且在有人启用之前一直保持关闭：即使账户回到限额之内，面板也不会自动恢复它们。**启用**会重新开启账户，但已过到期日或超出流量的账户除外，因为面板会立刻再次关闭它们。这些账户会被报告为仍保持关闭。见 [[use/users#disabling-and-enabling]]。

### 重置流量和重置设备 {#reset-traffic-and-reset-devices}

**重置流量**把账户的已用流量清零。累计总量会保留。

**重置设备**会遗忘账户在设备数限制下登记的所有设备，名额随之空出。已经拿到配置的设备会继续工作。

### 续期与赠送 {#extend-and-gift}

为到期时间增加天数，为流量额度增加流量：

- **增加天数**：正负最多十年。负数表示扣回天数。
- **增加流量**：以 GB 为单位。负数表示扣回流量。
- **已过期的账号从今天起算**：勾选后，一个十天前已到期的账户获赠 30 天时，会从今天起得到 30 天，而不是 20 天。尚未到期的账户仍在其原日期上累加。

增加天数需要账户有到期时间，增加流量需要账户有流量上限。永不过期或流量不限的账户会跳过对应部分，并在报告中列出。

使用面板 API 的程序还可以按自然月增加时长（见 [[reference/api]]）。

### 设置限额 {#set-limits}

在每个所选账户上设置**流量**、**到期时间**、**速度限制**、**地址数限制**、**设备数限制**和**周期重置**。只勾选你要修改的字段，其余字段保持原样。

- 设置**到期时间**会让账户变为固定日期：从首次连接起计算的时长会被该日期取代。
- 关闭周期重置也会清除其周期和下次重置日期。

### 允许的配置 {#allowed-configs}

在所有勾选的账户上设置同一个配置限制以替换其原有限制，或取消所有这些账户的限制（**取消限制**）。规则与用户表单中的相同（见 [[use/users#limiting-configs]]）。**设置此限制**至少需要一条规则：取消限制是单独的选项。只统计限制发生变化的账户。只销售套餐的代理不能执行此操作。

### 更改归属 {#change-owner}

把勾选的账户移交给某个管理员、某个代理商或面板。只更改归属：账户的限额、链接和节点保持不变。只有主管理员可以这样做。

移交给代理商的账户计入其配额；如果该代理商已过期，或其用户上限容纳不下全部所选账户，整个选择会被拒绝，一个账户也不会移动。

在面板开始记录创建者之前创建的账户归面板所有。主管理员就是用这个操作把它们交给负责的管理员。

### 导出 {#exports}

**下载 CSV** 是一张表格，每个账户一行，附带其订阅链接：适合交给他人的清单。**下载配置包**是一个 zip，包含每个账户的客户端配置。

::: warning
导出内容包含每个账户的订阅链接，而订阅链接等同于账户本身。即使关闭了变更日志，面板也会在[[use/audit|审计日志]]中记录每次导出。
:::

### 删除与删除过期用户 {#delete-and-delete-expired-users}

**删除**会永久移除所勾选的账户。

**删除过期用户…**会移除到期已超过你所填天数（默认 30 天）的所有账户，包括面板已经关闭的账户。它忽略页面的筛选条件。从首次连接起计算、但从未开始的账户不受影响。对话框会在你确认之前显示将删除多少个账户。

## 按名称模板批量创建用户 {#creating-many-users-from-a-name-pattern}

**批量创建用户…**一次创建一批账户，每次最多 500 个，每个账户都有自己的凭据。

1. 设置**数量**，以及带计数器或随机部分的**名称模板**：

   | 模板中的写法 | 生成结果 |
   | --- | --- |
   | `{n}` | 计数器：1、2、3… |
   | `{nnn}` | 补零到三位的计数器：001、002… |
   | `{r}` | 六个随机字符 |
   | `{r3}` | 三个随机字符 |

   `shop-{nnn}` 会生成 `shop-001`、`shop-002` 等。随机部分让别人无法猜出相邻的名称。一个模板最多只能有一个计数器，随机部分数量不限。**起始编号**设置计数器的第一个值。
2. 为这一批设置**分组**，便于日后查找。
3. 像创建单个用户一样，选择套餐或设置限额，并选择模板。**限制配置**会给这批账户中的每一个相同的配置限制。
4. 按**创建**。

已被占用的名称会被跳过，因此把同一批再运行一次即可补齐空缺。批量创建完成后，下载清单（**下载清单**）或配置包以便交付。如果许可证或代理商的用户数上限让批量创建中途停止，对话框会说明已创建多少个以及还剩多少名额。

## 被拒绝的操作及原因 {#what-is-refused-and-why}

有些账户不能被某些操作修改。面板会对其余账户执行操作，并报告被拒绝的账户，而不是让整个选择失败。

| 被拒绝的操作 | 原因 |
| --- | --- |
| 启用已过到期日或超出流量的账户 | 它会在一分钟内再次被关闭。请先续期。 |
| 为永不过期的账户增加天数 | 没有可推后的日期 |
| 为流量不限的账户增加流量 | 没有可提高的上限 |
| 对许可证之外的账户做任何修改 | 在你回到上限以内之前，它只能查看，但仍可删除。见 [[use/licence]]。 |
| 对仅按套餐售卖的代理商使用**续期与赠送**和**设置限额** | 其账户的限额来自套餐，只有你能修改 |
| **更改归属**给容纳不下全部所选账户的代理商 | 其用户上限只检查一次，针对所有账户合计 |
| 对关闭了**可以编辑和删除用户**的代理商做任何修改 | 它可以创建和导出账户，但不能修改或删除 |

如果耗时较长的操作被中断，报告会说明哪些账户已经处理过。再运行一次即可完成。
