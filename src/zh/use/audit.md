# 审计日志

审计日志记录管理员在面板中的操作：谁登录过；在开启变更记录时，还记录每一条被创建、修改或删除的记录，以及执行操作的账户。只有主管理员可以查看。它位于侧边栏的 **设置 → 审计日志**。

## 记录哪些内容 {#what-is-recorded}

无论设置如何，以下操作始终会被记录：

- 每一次面板登录，以及每一次登录失败和当时输入的用户名；
- 从账户未曾使用过的地址登录；
- 开启或关闭两步验证，以及生成新的恢复码；
- 每一次导出用户（CSV 列表或配置包），因为导出包含每个账户的订阅链接，且不会留下其他痕迹。

其他所有操作只在开启变更记录时才会记录。新面板默认关闭此功能。在 **设置 → 常规** 中开启 **记录管理员操作（审计日志）**，即可记录用户、节点、模板、入站、出站、端点、证书、管理员、API 令牌、许可证以及面板设置上的每一次创建、修改和删除。关闭时，页面会显示 *变更记录已关闭，不会再写入新记录。*，并附有该设置的链接。

没有管理员参与的操作，其管理员记为 **系统**。

## 查看记录 {#reading-a-record}

每一行显示 **时间**、**管理员**、**对象**（记录涉及的内容类型）和 **操作**。**查看记录** 会打开完整的记录及修改详情，你可以复制它。

机密信息永远不会被保存：密码、私钥、UUID 和令牌都显示为 `[redacted]`，新旧记录都是如此。

## 筛选 {#filters}

可以用以下条件缩小列表范围：

- **任意管理员**：某个账户，或 **系统**。
- **任意对象**：用户、节点、管理员、许可证等。
- **任意操作**：例如 **创建**、**修改**、**删除**、**安装**、**断开连接**，或登录。
- **起始日期** 和 **结束日期**：日期范围。

**清除筛选** 会重新显示所有记录。

## 记录保留多久 {#how-long-records-are-kept}

**记录保留天数** 位于 **设置 → 常规** 中记录开关的旁边，每小时自动删除一次过期的记录。`0` 表示全部保留，日志只会不断增长。即使关闭了变更记录，登录和导出仍会被记录，因此在繁忙的面板上无论如何都应设置保留期限。

备份默认包含审计日志，除非你在创建备份时将其省略（参见 [[use/backup]]）。

## 清空日志 {#clearing-the-log}

**清空日志** 会在确认后一次性删除所有记录。此操作无法撤销。如果开启了变更记录，清空操作本身会作为新日志的第一条记录被记下。
