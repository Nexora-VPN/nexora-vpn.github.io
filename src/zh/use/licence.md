# 许可证

[[~licence|许可证]]决定面板可以服务多少用户和节点。其他一切，包括所有协议和所有功能，在每个安装上都完全相同，无论是否授权。本页介绍 **许可证** 页面，只有主管理员可以打开它。

<NxShot page="license" alt="许可证页面：状态、购买或续费按钮、限额与用量表，以及许可证密钥字段" />

## 免费版 {#the-free-tier}

没有许可证时，面板以免费版运行：**25 个用户和 1 个节点**。每个页面顶部都会显示一条横幅说明这一点，并附有指向 **许可证** 页面的链接。

## 许可证页面 {#the-license-page}

| 部分 | 显示 |
| --- | --- |
| **状态** | **已授权**，以及许可证签发给的名称；或 **免费版** 及其原因，例如 *未安装许可证* 或 *许可证已过期* |
| **在线重新校验** | 立即询问许可证服务，并显示结果 |
| **最近一次经验证的校验** | 许可证服务最近一次应答的时间 |
| **购买许可证** / **续费或升级** / **将许可证迁移到本机** | 打开付款页面（见下文） |
| **限额与用量** | 用户和节点各自的现有数量（**已用**）和许可证覆盖的数量（**允许**）。超出限额的数量以红色显示。到期日期显示在表格下方。 |
| **许可证密钥** 和 **激活** | 用于手动收到的密钥 |

## 购买许可证 {#buying-a-licence}

1. 打开 **许可证**，点击 **购买许可证**。供应商的付款页面会在新标签页中打开，语言与面板一致。
2. 选择一个套餐，并使用页面提供的某种方式付款。无需注册账户；首次购买时页面会要求填写 Telegram 用户名或电子邮件地址，以便供应商联系你。
3. 回到面板。页面显示 *等待付款 — 确认后许可证会自动安装。*

无需粘贴任何密钥。付款确认后，许可证会在一两分钟内自动安装，页面显示 **许可证已安装**。凭收据付款需要等待供应商审核通过；页面会说明这一点，在此期间你可以关闭该标签页。

如果浏览器拦截了新标签页，请改用页面显示的链接（**打开付款页面**）。付款链接只对打开它的面板有效。

供应商手动发送给你的密钥依然可用：把它粘贴到 **许可证密钥** 中，然后点击 **激活**。

## 续费与升级 {#renewing-and-upgrading}

在已授权的面板上，该按钮显示为 **续费或升级**。付款页面会列出该许可证可以转换到的所有套餐，并已算好价格：

- **续费** 同一套餐会在当前到期日之后增加一个周期，因此提前续费不会有任何损失。
- **升级** 到更高的上限，会按剩余天数收取差价，到期日保持不变。

已过期的许可证也以同样的方式续费，付款确认后立即恢复。

## 迁移到新服务器 {#moving-to-a-new-server}

许可证与安装它的服务器绑定。要把它带到新服务器，请使用迁移功能：

1. 在新服务器上安装面板，并在设置向导中还原你的备份（**从另一台服务器迁移？从备份还原**）。参见 [[use/backup]]。新面板以免费版启动。
2. 打开 **许可证**，点击 **将许可证迁移到本机**。在付款页面上确认迁移。迁移是免费的。

有些迁移会立即完成。另一些需要等待供应商批准，页面会说明属于哪种情况；迁移获批后许可证会自动安装。迁移完成后，旧服务器会退回免费版。

## 达到上限与到期时 {#at-the-cap-and-at-expiry}

超出上限时，不会删除任何内容：

- 超出上限的行会被列出并标记为 **许可证之外**。按创建顺序排在前面的用户和节点仍在许可证范围之内。
- 许可证之外的行不会在任何节点上提供服务，也不能编辑。你可以打开查看，也可以删除它。
- 删除一些行腾出空间，或购买更多授权，被标记的行就会重新获得服务。

许可证到期时也是如此：面板退回免费版的 25 个用户和 1 个节点，并标记其余部分。到期后没有宽限期。面板会提前发出警告：

- 从到期前七天起，每个页面都显示一条横幅；
- 在到期前 30、14、7 和 1 天发出 `panel.license_expiring` 事件，你可以把它发送到 [[use/telegram|Telegram]]、[[use/email|电子邮件]] 或 [[use/webhooks|webhook]]。

超出上限后创建用户或节点会被拒绝，并提示已达到许可证限额。

## 保持连接 {#staying-in-contact}

面板需要能够通过 HTTPS 访问 `license.nexora-panel.org`。如果连续 14 天无法访问，面板会以免费版运行，直到恢复访问为止；在此之前一周会有横幅提醒。如果服务器位于防火墙之后，请放行到该地址的出站 HTTPS。**在线重新校验** 会立即尝试连接。

## 咨询与退款 {#questions-and-refunds}

面板和付款页面上都没有退款按钮。供应商的 Telegram、电子邮件地址和电话号码位于每个付款页面的底部。
