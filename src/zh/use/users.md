# 用户

[[~user|用户]]是你的一位客户：一个带有凭据、流量额度、到期时间和可选限制的账户。本页面列出你能看到的账户，用于创建新账户，并分发每个账户的[[~subscription|订阅]]链接。一次处理多个账户的批量操作见 [[use/user-operations]]。

<NxShot page="users" alt="用户页面：顶部是正常、已过期和流量已用尽账户的统计条，下方列表显示用量条、到期日期、分组标签和每个账户的归属，“仅我的用户”开关已打开" />

## 列表 {#the-list}

每行显示账户的**名称**（在线时带绿点，并显示它最近一次连接所用的入站）、**状态**、相对于其流量额度的**用量**、**到期时间**、客户端最近一次拉取订阅的时间（**最近拉取**）、**分组**，以及——对主管理员和管理员——**归属**。

| 状态 | 含义 |
| --- | --- |
| **正常** | 已启用，且在限额之内 |
| **尚未开始** | 其套餐从首次连接开始计算，而它还没有连接过 |
| **已过期** | 已过到期日期 |
| **流量已用尽** | 已用完全部流量 |
| **已停用** | 已关闭 |

正常账户的**最近拉取**显示**从未拉取**，通常说明客户从未导入链接。值得在它变成工单之前先发个消息问问。

### 统计条 {#the-summary-strip}

列表上方的计数器为**用户**、**在线**、**尚未开始**、**已过期**、**流量已用尽**、**已停用**、**正常**和**从未拉取**。点击某个计数只显示这些账户。

### 仅我的用户 {#my-users-only}

主管理员和管理员能看到面板上的全部账户。搜索框旁的**仅我的用户**开关在每次打开页面时都是开启的，它把列表和统计条限定为归你所有的账户：

- 对管理员，是它创建的或移交给它的账户；
- 对主管理员，是面板自己的账户：任何主管理员创建的，以及程序使用不属于任何账户的 API 令牌创建的。

只有主管理员能为其他管理员或代理商创建用户，或在之后把用户移交给他们。管理员创建的一切都归其本人。

关闭它即可查看全部账户。**归属**列显示每个账户归谁；点击某个归属只显示该归属的账户。在筛选面板中选择归属会关闭**仅我的用户**。

代理商始终只能看到自己的账户，也没有这个开关。见 [[use/resellers]]。

### 搜索、筛选与排序 {#search-filters-and-sort}

搜索框匹配名称、分组、说明、备注或订阅 ID 的一部分，以及标准联系方式（Telegram、邮箱、电话和其他标准字段）的一部分。输入客户的电话号码即可找到其账户。

**筛选**会打开一个侧边面板：

- **状态**，以及**在线**（最近 90 秒内有流量的账户）。
- **协议**、**入站**、**端点**、**节点**和**模板**：能访问它们的账户。对协议、入站和端点而言，这指的是在其上提供服务，因此限制了配置的账户（见下文）在其限制不允许的地方不会出现。
- **分组**，以及**归属**（主管理员和管理员）：某个管理员、某个代理商，或**面板（超级管理员）**。
- **到期区间**（两个日期之间），或**永不过期**。
- **已用流量（GB）**的起止范围。
- **自动重置**开或关，以及**已拉取订阅**是或否。
- **客户资料**：精确匹配的 Telegram id、邮箱或电话。

**筛选**按钮上的数字是正在使用的筛选条件数。**全部清除**会移除所有条件。

旁边的排序菜单决定列表顺序：**最早创建**、**最新创建**、**最近更新**、**最近在线**、**名称 A→Z**、**名称 Z→A**、**流量最多**、**剩余最多**、**最快到期**和**最近拉取**。

列表会自动刷新。勾选了行或打开了对话框时，刷新会暂停。

## 创建用户 {#creating-a-user}

按**添加**。表单有三个标签页：**设置**、**客户**和**凭据**。

<NxShot page="user-new" alt="新建用户表单：名称、分组、模板，然后是套餐选择器和限额" />

### 设置 {#settings}

| 字段 | |
| --- | --- |
| **名称** | 账户名称，显示在面板和客户的应用中 |
| **已启用** | 正常使用的账户需开启 |
| **分组** | 一个自由填写的标签，便于一起查找和处理账户。见 [[use/user-operations]]。 |
| **备注** | 加在客户应用中每个条目名称的前面 |
| **归属** | 仅限主管理员：该账户归谁——某个管理员、某个[[~reseller\|代理商]]，或**面板（超级管理员）**。只有主管理员能为他人创建用户；管理员创建的账户始终归其本人。代理商的账户计入其配额，管理员的不计。 |
| **订阅 ID** | 账户订阅链接中的标识。保持自动生成的值即可。 |
| **说明** | 给你自己看的备忘 |
| **全部模板**、**模板** | 账户在哪些模板上、也就是哪些节点上提供服务（见下文） |
| **限制配置** | 账户只在其模板的部分入站和端点上提供服务（见下文） |

### 限额 {#limits}

**套餐**决定限额从何而来：

- **无限制**：没有任何限制。
- **手动设置限制**会展开下面的字段。
- **选择某个套餐**会把该套餐的限额一次性复制到账户上。见 [[use/plans]]。

| 限额 | |
| --- | --- |
| **流量** | 以 GB 为单位的流量额度。`0` 表示不限。 |
| **到期时间** | 账户停止的日期。留空表示永不过期。 |
| **从首次连接开始计算** | 账户时长从首次连接开始计算，而不是从某个日期（见下文） |
| **速度限制** | 每个方向的 Mbps。`0` 表示不限。在每个节点上分别生效。 |
| **地址数限制** | 所有节点上可同时连接的来源地址数。`0` 表示不限。 |
| **设备数限制** | 可使用该订阅的设备数。`0` 表示不限。见下文。 |
| **自动重置** | 按周期重置已用流量（见下文） |

### 从首次连接开始计算 {#starting-on-the-first-connection}

开启**从首次连接开始计算**，并填写**套餐时长（天）**，不填日期。账户显示**尚未开始**，在首次产生流量之前不会过期。从那时起，它持续你填写的天数，表单会显示**开始于**的时间。

这适合预先售出的账户：客户即使一周后才设置好应用，仍能获得完整的时长。之后修改时长，会从下一次连接起重新开始计算。

### 重置周期 {#reset-cycles}

开启**自动重置**后，账户的已用流量会按周期归零，这样每月的流量就真的是每月的流量。**重置周期**有四种形式：

| 周期 | 重置时间 |
| --- | --- |
| **每 N 天** | 每隔**重置周期（天）**所填天数，从上次重置开始计算 |
| **每周** | 你所选的星期几（**重置于**） |
| **每月** | 某个**每月日期** |
| **每年** | 某个**月份**的某一天 |

**每月**和**每年**按**历法**计算：**公历**或**波斯历**。某个月没有的日期会落在该月最后一天（2 月的 31 日即 28 日），下个月再回到所选日期。表单会显示**下次重置**日期。

重置只清除已用流量，累计总量会保留。

### 模板 {#templates}

用户只在其所属[[~template|模板]]的节点上获得服务。

- **全部模板**让账户出现在每个节点上，包括以后新增的模板。这是新用户的默认设置。
- 关闭它时，选择一个或多个**模板**。不属于任何模板的账户无法访问任何节点。
- 当所有者是被限制在所选模板上的代理商时，表单只提供这些模板，开关显示为**该分销商的全部模板**（见 [[use/resellers#limiting-a-reseller-to-templates]]）。

### 限制配置 {#limiting-configs}

模板决定账户在哪些节点上。**限制配置**决定它在这些节点的哪些入站和端点上提供服务。开启后，表单会显示**入站**和**端点**的规则：

1. 选择一个**字段**：**协议**或**标签**；入站还可选 **TLS**（`none`、`tls` 或 `reality`）和**传输**（`ws`、`grpc`、`xhttp`……或 `none`）。
2. 选择一个**运算符**：**等于**、**不等于**、**属于**、**不属于**、**开头为**、**结尾为**或**包含**。TLS 只有前四个。
3. 选择或输入**值**：一个值、多个值，或者后三个运算符使用的文本（不区分大小写）。

配置须匹配其所在部分的每一条规则才被允许。没有规则的部分允许全部。规则可以指明账户模板中都没有的标签，它在那里只是匹配不到任何东西。每个部分最多 32 条规则，每条规则最多 64 个值。拖动规则的手柄，或聚焦手柄后使用方向键，即可调整顺序。

开关旁的**显示结果**会在规则下方列出账户模板中的入站和端点，并按面板为节点判断的方式标出每项是否允许。账户的节点、链接和应用配置只包含允许的项，修改无需重启节点即可生效。列表中受限账户的名称旁有一个筛选图标，悬停即可查看规则。

套餐不带限制。批量新建的用户可以带限制（见 [[use/user-operations#creating-many-users-from-a-name-pattern]]），**允许的配置**可在所选账户上设置或取消限制（见 [[use/user-operations#allowed-configs]]）。只销售套餐的代理不能更改它。

### 客户资料 {#customer-details}

**客户**标签页以字段和值的形式保存你对这位客户的了解。有六个标准字段：Telegram、Email、Phone、Bale、Soroush Plus 和 Rubika。只有这些字段会被搜索、筛选、导出，以及在导入时自动填入。用**添加字段**添加其他字段；它们随账户保存，但不会被任何功能读取。

Telegram、Bale 或 Soroush 的 id 是数字聊天 id 或 `@username`。客户关联通知扩展的机器人时，该扩展会自动填入这些字段（见 [[addons/notifier]]）。

### 凭据 {#credentials}

**凭据**标签页保存账户的 UUID、**密码**、Shadowsocks 密钥和 VLESS 的 **Flow**。它们自动生成，由所有协议共用，通常没有理由去改动。重新生成任意一项都会改变账户的链接，客户需要重新拉取订阅。

## 订阅链接与二维码 {#the-subscription-link-and-qr-codes}

行上的**订阅**按钮会复制账户的订阅链接。你交给客户的就是这一个链接：客户的应用从它拉取全部配置并保持更新。在浏览器中打开时，它显示[[~subscription-page|订阅页面]]，包括用量、到期时间和设置帮助。

行菜单中的**二维码 / 链接**有三个标签页：

- **订阅**：各种格式的链接（自动、Clash、sing-box 配置、Xray JSON 配置、纯文本），每个都附有可扫描的二维码。
- **链接**：每一条配置单独的分享链接和二维码。
- **客户端应用**：供专用应用使用的文件，例如 WireGuard 的 `.conf` 或 OpenVPN 的 `.ovpn`。文件太大无法生成二维码时，可以复制或保存。

[[use/subscriptions]] 介绍订阅页面的外观和订阅域名，[[how/subscriptions]] 说明链接是如何生成的。

## 设备与地址 {#devices-and-addresses}

行菜单中的**设备与地址**每十秒刷新一次，显示：

- 拉取过该订阅的**设备**。拉取时发送设备 id 的应用（Happ 和 v2RayTun 默认发送；Shadowrocket、Karing 和 Throne 需开启后发送）会被列出，并计入**设备数限制**。超出限制的设备拿不到配置。已经拿到配置的设备会继续工作，直到你**遗忘**它，从而腾出名额。
- **活跃地址**：账户在最近十分钟内从哪些地址连接，覆盖所有节点。
- 打开的会话数，并可进入**实时连接**。

不发送设备 id 的应用不会被列出；除非你在 [[use/subscriptions]] 中开启严格设置，它们也不受限制。

## 实时连接 {#live-connections}

行菜单中的**实时连接**显示该账户当前打开的连接：先选择节点，再按入站或出站筛选。每行显示连接的来源、目标、为其选路的规则、已打开的时长和流量。

**断开 {node} 上的全部连接**会关闭该账户在该节点上的连接，另一个按钮则关闭其在所有节点上的连接。关闭连接不是封禁：除非账户已停用，应用会在下一个数据包时重新连接。

行菜单还有**流量图表**（随时间变化的流量）、**按节点用量**（流量经过了哪些节点）和**路由测试**（某个连接会匹配哪条路由规则；见 [[use/routing]]）。

## 续期账户 {#renewing-an-account}

续期时，编辑账户并推后其**到期时间**或提高其**流量**，或使用**续期与赠送**为一个或多个账户增加天数或流量（见 [[use/user-operations]]）。因到期或流量用尽而被面板关闭的账户，在重新回到限额之内后，一分钟内会自动恢复。

NX Shop 等程序通过面板 API 为账户续期（见 [[reference/api]]）。

## 停用与启用 {#disabling-and-enabling}

在表单中关闭**已启用**，或对所选账户使用**停用**，即可关闭账户。由谁关闭的很重要：

- **你关闭的。**即使在限额之内，它也保持关闭，直到有人将其启用。
- **面板关闭的**，原因是账户到期、流量用尽，或其代理商的配额用尽。账户重新回到限额之内后（例如续期后），会自动恢复。

对所选账户使用**启用**时，已过到期日或超出流量的账户会保持关闭，面板会告诉你有多少个；请先为它们续期。

## 超出许可证的用户 {#users-beyond-the-licence}

免费版为 25 个用户提供服务。超出许可证允许范围的账户会被标记为**许可证之外**：它们会被列出，可以删除，但不会在任何节点上获得服务，也不能修改。列表上方的提示会统计它们的数量。见 [[use/licence]]。
