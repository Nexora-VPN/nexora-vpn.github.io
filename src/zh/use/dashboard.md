# 仪表盘

仪表盘是面板打开时的首页。它显示面板自身服务器、各节点和用户的运行情况，其中大部分内容由你决定显示什么。

<NxShot page="dashboard" alt="仪表盘：一排计数器，服务器状态和集群总览磁贴，下方是节点状态表和流量排行" />

## 快速上手 {#getting-started}

新面板在最上方显示一张**快速上手**卡片。它按顺序列出客户的链接能用之前需要的五样东西：一个入站、一个包含该入站的模板、一个节点、节点上指定该模板，以及一个用户。每一步都链接到对应的页面，条件满足后该步会被勾选。五步全部完成，或你按下**隐藏此指南**后，卡片会自动消失。[[start/index]] 介绍的是同样的步骤。

## 统计条 {#the-summary-strip}

卡片下方的一排计数器：

| 计数器 | 统计内容 |
| --- | --- |
| **用户** | 你能看到的所有账户 |
| **在线用户** | 最近 90 秒内有流量的账户 |
| **活跃用户** | 处于启用状态的账户 |
| **已连接节点** | 面板当前能连上的节点数，以及节点总数 |
| **入站** | 池中的入站 |
| **模板** | 模板 |
| **总流量** | 每个节点自添加以来承载的全部流量 |

## 磁贴 {#tiles}

统计条下方是磁贴：小型的实时仪表、图表和读数。按**磁贴**选择要显示哪些。固定的磁贴随你的账户保存，因此在任何浏览器中都一样；其他管理员各自选择自己的磁贴。

- 按住磁贴的标题栏**拖动**可移动它。
- 磁贴标题栏中的 **×** 用于取消固定。
- 页面打开期间，磁贴每隔几秒刷新一次。**磁贴**按钮旁的一行文字显示已固定的数量和刷新间隔。

新账户默认固定服务器和集群磁贴。节点磁贴默认不固定，因为它们描述的是某一个节点，由你来选。

磁贴分为三组，仪表盘把每组显示在各自的区域中。

### 服务器：面板所在的机器 {#server-the-panels-own-machine}

显示在**服务器状态**下，附带面板的版本和安装方式。

| 磁贴 | 显示内容 |
| --- | --- |
| **服务器系统** | 面板的版本、CPU 核数、内存、磁盘和运行时长 |
| **服务器 CPU 负载** | 负载占 CPU 核数的比例，以及平均值和峰值 |
| **服务器内存** | 面板服务器已使用的内存 |
| **服务器进程** | 面板程序本身使用的内存 |
| **数据库** | 数据库类型和大小、用量记录行数，以及其中的用户、节点和入站数量 |
| **备份** | 上次备份的时间、是否开启自动备份，以及服务器上的备份归档数量。备份逾期时，时间显示为琥珀色。 |
| **许可证** | 已授权或免费版、到期时间，以及已用用户数和节点数与上限的对比 |

**备份**和**许可证**仅限主管理员：其他账户在选择器中看不到它们。见 [[use/backup]] 和 [[use/licence]]。

### 集群：所有已连接节点 {#fleet-every-connected-node}

显示在**集群总览**下，附带已连接节点的数量。

| 磁贴 | 显示内容 |
| --- | --- |
| **集群吞吐** | 所有已连接节点的下载和上传速率，包括当前值和最近几分钟的曲线 |
| **各节点负载** | 每个节点一条 CPU 曲线 |
| **各节点内存** | 每个节点一条内存曲线 |
| **流量占比** | 各节点在总流量中所占的比例。未连接的节点显示为灰色，并标明其状态。 |
| **在线用户** | 在线账户数与账户总数的对比 |

### 节点：一次一个节点 {#node-one-node-at-a-time}

显示在**实时磁贴**下。上方的一排节点名称用于选择这些磁贴描述哪个节点。

| 磁贴 | 显示内容 |
| --- | --- |
| **CPU 负载**、**内存** | 该节点的仪表 |
| **负载历史**、**内存历史** | 同样的数据在最近几分钟内的曲线 |
| **网络** | 该节点的吞吐 |
| **系统** | 机器信息：名称、地址、CPU、负载、磁盘、Swap、运行时长 |
| **Nexora 节点** | 节点程序：是否运行、版本、运行时长、流量、在线用户 |

磁贴中的短横线（**—**）表示节点没有上报该数据，并不表示为零。

## 节点状态 {#node-status}

磁贴下方的表格列出每个节点的**状态**、**运行时长**、内存（**RAM**）、**负载**和**流量**。将指针移到流量数字上，可查看其上传、下载以及在整个集群中的占比。[[use/nodes]] 页面有完整的详情和所有操作。

| 状态 | 含义 |
| --- | --- |
| `connected` | 面板能连上该节点，节点正在提供其配置的服务 |
| `connecting` | 面板正在连接该节点 |
| `error` | 面板连不上该节点，或节点拒绝了其配置。节点页面会显示原因。 |
| `disabled` | 你关闭了该节点 |

## 流量排行 {#top-users-by-usage}

表格旁的列表显示流量最多的八个账户。绿点表示该账户当前在线。点击某个账户，可查看它在你选择的时间段内在哪些节点上使用了流量（**按节点用量**）。这需要**流量、报表与健康状态**权限。

## 代理商看到的内容 {#what-a-reseller-sees}

[[~reseller|代理商]]看到的是另一种仪表盘，只涉及它自己的业务：

- **我的配额**：已用流量与流量配额的对比、剩余量、重置周期和账号到期时间。
- 计数器：**我的用户**（与其用户数上限对比）、**在线用户**、**活跃用户**和 **7 天内到期**。
- **我的用户**：其账户列表。

见 [[use/resellers]]。
