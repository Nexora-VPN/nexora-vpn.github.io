# 代理商

[[~reseller|代理商]]是向自己的客户销售的管理员账户。它只能看到和管理自己创建的用户，并受你设定的配额约束：每个周期的流量、到期日期、用户数量，以及可选的可销售套餐。本页介绍如何设置代理商以及它能看到什么。

<NxShot page="admins" alt="管理员页面：操作员和代理商账户，显示每个代理商的配额和到期时间" />

## 代理商能做什么 {#what-a-reseller-can-do}

代理商登录同一个面板，能看到两个页面：

- **仪表盘**：它的配额（已用和剩余流量、重置周期和账号到期时间）、用户计数器，以及它自己的用户列表。
- **用户**：只有它自己的客户。它可以创建客户、分发链接，并在你允许时编辑和删除客户。筛选、搜索、批量操作和导出都作用于它自己的账户。

它永远看不到其他代理商的客户、你自己的客户、节点、模板或设置。你开启了相应服务时，其客户的通知可以通过**我的 Telegram** 和**我的邮件**发送给它（见 [[use/telegram]] 和 [[use/email]]）。

## 设置代理商 {#setting-up-a-reseller}

代理商由主管理员在**访问控制 → 管理员**中创建。

1. 按**添加**，填写**用户名**和**密码**。
2. 把**角色**设为**分销商**，或设为你基于代理商层级自建的角色（见 [[use/roles]]）。
3. 填写配额：

   | 字段 | |
   | --- | --- |
   | **流量配额** | 该代理商所有用户每个周期可用的流量，以 GB 为单位。`0` 表示不限。 |
   | **重置周期** | **不重置**、**每周**、**每月**或**每年**，以及用于指定星期几或每月几号的**重置日** |
   | **账号有效期（自现在起的天数）** | 代理商账户何时结束。`0` 表示永不。 |
   | **最大用户数** | 它最多可拥有多少个账户。`0` 表示不限。 |

4. 设置它能做什么：

   | 字段 | |
   | --- | --- |
   | **可以编辑和删除用户** | 关闭：它可以创建账户，但之后不能修改或删除 |
   | **仅按套餐售卖** | 开启：它创建的每个账户都必须来自**允许的套餐**之一，并使用套餐的限额（见 [[use/plans#plans-for-resellers]]） |
   | **仅限所选模板** | 开启：它的客户只会放在**允许的模板**上，因此只能使用这些模板的节点（见下文） |
   | **订阅域名** | 其客户的链接使用你的哪个订阅域名（见下文） |

5. 按**保存**，把登录信息交给代理商。

在管理员列表中，**配额**列显示每个代理商已用流量与流量配额的对比，到期日期显示在其名称下方。

### 流量配额 {#traffic-allowance}

代理商的流量是其客户自当前周期开始以来的流量总和，按客户的计费方式统计：每个节点的流量倍率都会生效。周期重置时，统计重新开始。

### 角色上的限制 {#limits-on-a-role}

基于代理商层级的角色可以带有三项上限，作用于该角色下的每个账户，并叠加在每个账户自己的配额之上：

- **每账号用户数**：该角色下的账户最多可拥有多少用户。
- **每用户设备数**：它能给用户设置的最高设备数限制。此时完全不设设备数限制的用户会被拒绝。
- **套餐时长（天）**：它能销售的最长套餐。

角色上限与账户自身的值，取两者中较严格的那个。见 [[use/roles]]。

## 把代理商限制在部分模板上 {#limiting-a-reseller-to-templates}

节点只为其[[~template|模板]]的用户服务，所以要给代理商一部分节点而不给另一部分，就给它一部分模板。打开**仅限所选模板**，并选择**允许的模板**。

- 代理商只能看到这些模板，它的用户表单也不会提供其他模板。它的客户的**全部模板**指的是该代理商的全部模板。
- 面板会收窄，而不是拒绝。列表之外的模板会从任何请求中去掉：创建、编辑、包含更多模板的套餐，或你通过**归属**或**更改归属**交给代理商的客户。
- **保存代理商时，列表会应用到它的所有客户。**移除一个模板，它的所有客户会立即离开该模板及其节点，节点无需重启。添加一个模板，它会加给使用全部模板的客户；手动选择了模板的客户保留原来的选择。面板会告诉你这次保存调整了多少客户。

要把共用一个模板的两个节点分开，就给它们各自一个模板。如果所有允许的模板都被删除，代理商仍然被限制在空列表上：它的客户无法访问任何节点，管理员列表会把它标成红色，直到你选择一个模板。

## 每个代理商一个订阅域名 {#a-subscription-domain-per-reseller}

当你有多个订阅域名时，**订阅域名**决定代理商的客户发布在哪个域名下。保持默认时，使用第一个已配置的域名。

只有主管理员能设置这一项。域名是被整体封锁的单位，所以选择域名就是在选择哪些人的客户会一起失联。如果你移除了某个代理商所用的域名，其客户会转到第一个已配置的域名。见 [[use/subscriptions]]。

## 代理商额度用尽时 {#when-a-reseller-runs-out}

面板每分钟检查一次每个代理商。

- **超出流量配额**：它的所有客户都会被关闭，直到下一个周期开始，然后重新启用。
- **超过账号到期时间**：它的所有客户都会被关闭，代理商也无法再使用面板。登录时它会看到*此账户已过期*，打开的会话结束，其 API 令牌也会失效。

为代理商续期（在管理员页面提高其配额或推后其到期时间）后，它可以立即重新登录，其客户会在一分钟内恢复。由你或代理商手动关闭的客户保持关闭。

## 删除代理商 {#deleting-a-reseller}

删除代理商会把它的客户转交给面板：这些客户在原有模板上继续正常使用，并成为你的客户。绑定到该代理商的 API 令牌会一并删除。
