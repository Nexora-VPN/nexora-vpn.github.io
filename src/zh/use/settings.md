# 常规设置

**设置 → 常规** 决定如何访问面板本身，以及几项全面板范围的选项。大多数会改变面板地址的设置在重启后生效，并且只有主管理员可以修改。

<NxShot page="settings" alt="常规设置页面：Web 服务器、订阅与集成、规则集镜像、预设目录、时区、流量图表和审计日志等卡片" />

::: warning
错误的地址、路径或监听设置可能让你无法访问面板。每一项都可以在面板未运行时从服务器命令行恢复。参见 [[reference/cli]]。
:::

## 面板的地址 {#the-panel-s-address}

**Web 服务器** 卡片决定面板在哪里响应。

| 设置 | 作用 |
| --- | --- |
| **面板域名（可选）** | 设置后，面板只响应发往该主机名的请求。 |
| **面板基础路径（可选）** | 在某个路径下提供面板，例如 `/panel`。该路径之外的请求到达不了登录页。 |
| **监听 IP** | 面板绑定的地址。留空则绑定所有地址，包括 IPv4 和 IPv6。 |
| **监听端口** | 面板监听的端口。 |

设置向导会建议一个随机的基础路径。请保留它：它让登录页不出现在面板的裸地址上，下面的订阅域名和网站功能也依赖它。

在 Docker 中，监听地址由 compose 文件决定，因为端口映射也在那里，相关字段会注明这一点。请在 compose 文件中同时修改两者。参见 [[start/install-panel]]。

这些修改在点击 **重启面板** 后生效。如果服务器无法绑定新地址，面板会退回到之前的地址。

## 面板的 HTTPS {#https}

**面板 HTTPS** 决定面板如何提供自己的网页界面：

| 选项 | 含义 |
| --- | --- |
| **面板中的证书** | 使用 [[use/certificates]] 证书库中的一张证书，包括由 ACME 签发的证书。续期后无需重启即可生效。 |
| **磁盘上的证书文件** | **SSL 证书文件** 和 **SSL 私钥文件**：面板服务器上的路径。 |
| **纯 HTTP（无证书）** | 不使用 TLS。密码和订阅链接以明文传输。 |

设置向导一开始会使用证书库中的一张自签名证书。要使用真实域名，请在证书页面为它签发 ACME 证书，在这里选中它，然后重启。

如果证书由你自己管理，它还必须包含每一个订阅域名；参见 [[use/subscriptions#subscription-domains]]。

## 其他地址上的网站 {#a-web-site-for-other-addresses}

**伪装目录** 接受面板服务器上的一个绝对路径。之后，发往面板端口、但既不是访问面板也不是访问订阅的请求，会由该目录作为你提供的普通网站来响应：落地页、公司网站，或任何适合该地址的内容。

- 它需要设置 **面板基础路径（可选）**。如果面板位于根路径，就没有留给网站的地址了。
- 面板本身不附带任何网站。请放入你自己的文件，并提供一个 `404.html`，用于没有对应文件的路径。
- 它不列出目录内容，不提供以点开头的文件，也不跟随指向目录之外的链接。
- 它从不影响面板的 API：未认证的 API 请求仍然得到面板自己的响应。
- 它在重启后生效。

## 订阅与集成 {#subscriptions-and-integrations}

这张卡片设置用户订阅链接指向的位置：**订阅域名（可选）**、**订阅基础路径（可选）** 和 **公开地址**。它们与其余订阅设置一起在 [[use/subscriptions]] 中介绍。

## 规则集镜像与预设目录 {#rule-set-mirror-and-preset-catalogue}

- **规则集镜像 → 存储目录**：面板保存每个规则集副本的位置。使用绝对路径；留空则保存在数据库旁边。参见 [[rule-sets]]。
- **预设目录 → 目录路径**：面板读取你自己的预设文件的位置。卡片会列出当前生效的文件。参见 [[routing#your-own-presets]]。

## 时区 {#timezone}

**面板时区** 决定面板、日志和订阅页面中所有时间戳使用的时区，也决定流量图表上一天从何时开始。时区数据库内置在面板中，因此无论服务器如何设置，每个时区都可用。**服务器默认** 表示跟随服务器的时区。

## 流量图表与审计日志 {#usage-graphs-and-audit-log}

- **流量图表**：**采样保留天数** 和 **采样间隔（秒）** 决定为各列表页上的图表保留多少流量历史。天数设为 `0` 会关闭图表并清除已保存的数据。
- **审计日志**：**记录管理员操作（审计日志）** 会记录每一次创建、修改和删除，以及执行操作的账户，保留 **记录保留天数** 所设的天数。参见 [[audit]]。

这里的 **语言** 选择器用于设置你的浏览器中面板显示的语言。

## 登录保护 {#login-protection}

受信任代理、登录白名单和地址封禁位于 **设置 → 安全**，与双因素认证和会话管理放在一起。参见 [[use/security]]。如果面板位于反向代理或 CDN 之后，请先在那里设置 **受信任代理**，再依赖登录封禁。

## 重启面板 {#restarting-the-panel}

**重启面板** 会重启面板，使地址、路径、监听和 HTTPS 的修改生效。面板恢复后页面会自动重新加载。用户的连接不受影响：面板重启期间节点继续提供服务。
