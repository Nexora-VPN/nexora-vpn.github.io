# 套餐

[[~plan|套餐]]是创建新用户时套用的一组限额预设：流量、时长、设备和速度限制、重置周期以及模板。把你销售的产品做成套餐，同一类账户就都以相同的方式开始。

<NxShot page="plans" alt="套餐页面：套餐列表，显示每个套餐的流量、时长、限额和分组" />

## 套餐只套用一次 {#a-plan-is-applied-once}

从套餐创建用户时，面板把套餐的数值复制到账户上，仅此而已。此后账户与套餐之间没有任何关联。

- 编辑套餐永远不会改变已经用它创建的账户。你可以调整目录中的价格和限额，而不影响客户已经购买的内容。
- 删除套餐后，其账户保留当初获得的所有限额。
- 之后编辑账户时，不会重新套用其套餐。

套餐在账户上留下的唯一痕迹是它的**分组**（见下文），你靠它再次找到该套餐的账户。

## 创建套餐 {#creating-a-plan}

在**套餐**页面（侧边栏中**用户**下方）按**添加**。

| 字段 | |
| --- | --- |
| **名称** | 套餐在用户表单中显示的名称 |
| **排序** | 套餐在列表中的位置。数值相同时按创建顺序排列。 |
| **流量** | 以 GB 为单位的流量额度。`0` 表示不限。 |
| **时长（天）** | 账户可用多久。`0` 表示永不过期。 |
| **从首次连接开始计算** | 时长从客户首次连接时开始计算，而不是从创建时（见下文） |
| **速度限制**、**地址数限制**、**设备数限制** | 与用户上的相同。`0` 表示不限。见 [[use/users]]。 |
| **自动重置** | 按周期重置已用流量：每 N 天、每周、每月或每年，可按公历或波斯历计算。见 [[use/users#reset-cycles]]。 |
| **全部模板**、**模板** | 该套餐的账户在哪些模板上、也就是哪些节点上提供服务 |
| **分组** | 写入该套餐创建的每个账户 |
| **用户名前缀**、**用户名后缀** | 加在创建时输入的名称两侧：前缀 `r1_` 会把 `ali` 变成 `r1_ali` |
| **说明** | 给你自己看的备忘 |

## 固定日期还是首次连接 {#fixed-date-or-first-connection}

**从首次连接开始计算**决定时长何时开始：

- **关闭：固定日期。**到期时间在账户创建时确定：今天创建的 30 天套餐会在 30 天后结束，不论客户是否使用过。列表中只显示时长。
- **开启：自首次连接起。**账户处于**尚未开始**状态，在首次产生流量之前不会过期。时长从那时开始计算。列表中这类套餐标有**自首次连接起**。

预先售出的账户请选择后者，例如批量交给代理商或印在卡片上的账户：没有人会因为设置应用花了时间而损失天数。

## 从套餐创建用户 {#creating-users-from-a-plan}

在用户表单中，**套餐**提供**无限制**、**手动设置限制**以及所有套餐。选择某个套餐会填入其限额并将其隐藏，因为这些数值属于套餐。表单会显示加上套餐前缀和后缀后的最终名称（**将保存为 {name}**）。

批量创建（**批量创建用户…**）也可以选择套餐，让整批账户以相同的设置开始。见 [[use/user-operations]]。

## 代理商的套餐 {#plans-for-resellers}

套餐也是你控制[[~reseller|代理商]]销售内容的方式。在**管理员**中该代理商的账户上：

1. 开启**仅按套餐售卖**。
2. 选择**允许的套餐**。

此后，该代理商创建的每个账户都必须来自这些套餐之一，并且无论请求中填了什么，面板都套用套餐的限额。代理商之后可以修改账户的名称和凭据，但不能修改任何一项限额。它只能看到自己可以销售的套餐。见 [[use/resellers]]。

角色还可以限制其账户所能销售的最长套餐（**套餐时长（天）**），从客户首次连接时开始计算。见 [[use/roles]]。
