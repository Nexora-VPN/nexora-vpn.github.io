# 使用面板

本节按侧边栏的顺序逐一介绍[[~panel|面板]]的各个页面。先从这里了解界面本身：各项功能在哪里、如何用键盘到达，以及所有列表页和对话框的共同点。

<NxShot page="dashboard" alt="面板的仪表盘：左侧是侧边栏，顶栏有搜索、语言和主题按钮，仪表盘磁贴上方是一排计数器" />

## 界面 {#the-screen}

面板分为三部分：

- **侧边栏**位于左侧，列出你的账户可以打开的页面。
- **顶栏**显示当前页面的名称，然后是搜索按钮、语言按钮、主题按钮和你的账户菜单。
- **页面**占据其余部分。关于许可证或新版本的横幅出现在顶栏和页面之间。

在桌面端，侧边栏收起为一列图标，鼠标指向时展开。名称旁的图钉（**固定菜单**）让它保持展开。在手机上，侧边栏是一个抽屉：用顶栏的菜单按钮打开。

## 侧边栏 {#the-sidebar}

侧边栏只显示你的角色允许的内容。某个分组若没有你可打开的页面，就会整个消失。主管理员看到的菜单如下：

| 菜单项 | 内容 |
| --- | --- |
| **仪表盘** | 面板、集群和用户的概览 |
| **节点** | 承载流量的服务器 |
| **隧道** | 两组节点之间的连接 |
| **用户** | 客户的账户 |
| **套餐** | 创建新用户时使用的预设 |
| **证书** | 用于入站和面板自身的 TLS 证书 |
| **核心配置** | **模板**、**入站**、**出站**、**端点**、**规则集**、**域名前置** |
| **设置** | **常规**、**订阅**、**地址**、**备份**、**安全**、**面板更新**、**审计日志** |
| **服务** | **Webhook**、**Telegram**、**邮件**、**备份目的地**、**单点登录**、**扩展** |
| **访问控制** | **管理员**、**角色**、**API 令牌** |
| **许可证** | 许可证及其允许的范围 |

使用内置运营者角色的管理员看到的菜单相同，但没有**服务**、**访问控制**、**许可证**，以及**设置**下仅限主管理员的页面（**地址**、**备份**、**安全**、**面板更新**、**审计日志**）。自定义角色可以去掉更多页面。[[~reseller|代理商]]只能看到**仪表盘**和**用户**。各项权限能打开哪些页面，见 [[use/roles]]。

**扩展**旁边的圆点（分组**服务**折叠时也会显示在其上）表示扩展目录中有你正在运行的某个扩展的新版本。

## 账户菜单 {#the-account-menu}

点击顶栏右侧你的名字，可打开你自己账户的设置：

- **修改密码**
- **两步验证**：每次登录时输入验证器应用中的验证码。见 [[use/admins]]。
- **会话**：所有登录了你账户的浏览器，并可将其登出。
- **我的 Telegram**、**我的邮件**、**单点登录**：主管理员开启这些服务后，用于你自己账户的通知和登录。见 [[use/telegram]]、[[use/email]] 和 [[use/sso]]。
- **退出登录**

## 命令面板 {#the-command-palette}

按 **Ctrl+K**（Mac 上为 **Cmd+K**），或在未输入文字时按 **/**，或点击顶栏的搜索按钮。然后输入：

- **页面**：侧边栏中的任意页面，按名称搜索。
- **操作**：创建记录，例如**新建用户**、**新建节点**或**新建入站**。命令面板会打开对应页面，并直接打开创建对话框。
- **用户**：按名称、分组或订阅 ID 搜索账户。选中后会打开筛选到该账户的用户页面，在那里使用该行自己的操作。

用方向键移动，按 Enter 打开，按 Escape 关闭命令面板。

## 主题、主色与密度 {#theme-colour-and-density}

顶栏的主题按钮决定面板的外观：

| 设置 | 选项 |
| --- | --- |
| 模式 | **跟随系统**（随设备设置）、**浅色**、**深色**、**高对比度** |
| **主色** | **紫色**、**海洋**、**森林**、**日落**、**玫瑰** |
| **紧凑布局** | 更小的文字和更紧凑的行，一屏显示更多内容 |

这些选择保存在浏览器中，因此每台电脑可以有各自的设置。仪表盘磁贴则不同：它们跟随你的账户（见 [[use/dashboard]]）。

## 语言 {#languages}

语言按钮可在英语、波斯语（فارسی）、中文和俄语（Русский）之间切换面板。波斯语会把整个布局切换为从右到左。该选择保存在浏览器中。

日期和时间按面板自身的时区显示，与你电脑的时区无关；时区由主管理员在**设置 → 常规**中设置（见 [[use/settings]]）。

## 列表页的用法 {#how-list-pages-work}

大多数页面是记录列表，用法都相同：

- **顶部的统计条**按状态统计记录数，例如已连接和出错的节点。点击某个计数只显示这些行，再点一次取消。
- **标题行**有**添加**按钮和搜索框。用户页面还有**筛选**和排序菜单（见 [[use/users]]）。
- **第一列**是每行的操作：几个按钮，其余操作在 **⋮** 中。在手机上，这些按钮收进 **⋮** 菜单，放不下的列收进每行的 **ⓘ** 按钮。
- **勾选多行**可一次处理多条记录。勾选后，**添加**旁边会出现批量操作按钮。面板会逐条处理所选记录，并报告哪些行失败及原因。
- **删除和其他破坏性操作会先确认。**

许可证未覆盖的行会变暗，并标记为**许可证之外**。你可以打开查看，也可以删除，但不能修改。见 [[use/licence]]。

## 对话框的行为 {#how-dialogs-behave}

创建或编辑记录时，会在页面上方打开一个对话框。在你按下**保存**之前，什么都不会保存。面板返回的错误会以消息形式出现在屏幕角落，对话框保持打开，你可以改正字段后重试。

有些操作属于敏感操作：管理管理员和 API 令牌、安装许可证、恢复备份、重启面板，以及修改面板的地址设置。如果你的账户启用了两步验证，面板会在执行此类操作前要求输入新的验证码，最多每十分钟一次。

需要在查看时保持页面可见的内容，例如用户筛选或节点日志，会以抽屉形式从侧边滑出。
