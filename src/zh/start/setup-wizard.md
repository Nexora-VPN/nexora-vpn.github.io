# 设置向导

[[~setup-wizard|设置向导]]是安装程序打印的链接所打开的页面。它创建主管理员，并决定面板在哪里、以何种方式响应。页面上的所有内容会一次性一起保存，随后面板重启到你填写的地址上。

<NxShot page="setup-wizard" alt="设置 Nexora 表单：主管理员、面板地址、HTTPS 和时区" />

## 一次性链接 {#the-one-time-link}

安装程序会打印类似 `http://203.0.113.10:28431/setup?t=9f3c1ad2…` 的链接。末尾的令牌决定了谁能创建主管理员，所以请像对待密码一样对待这个链接。

- **只有这个链接能打开向导。** 设置完成之前，面板不显示任何其他内容：登录页、API 和订阅链接都返回“not found”，不带令牌的设置页也是如此。
- **它在设置完成前一直有效。** 之后令牌失效，面板显示登录页。
- **链接丢了？** 在服务器上运行 `nexora-panel setup-token` 会重新打印它。`nexora-panel setup-token -rotate` 会换成一个新令牌，旧链接随之作废。

页面顶部有语言切换和主题切换。

## 主管理员 {#main-administrator}

能够重新配置面板并查看所有订阅的账户。它会成为面板的 **所有者**：唯一不能被删除或降级的账户。

| 字段 | 规则 |
| --- | --- |
| **用户名** | 3 到 32 个字符 |
| **密码** | 至少 12 个字符，包含以下四类中的三类：小写字母、大写字母、数字、符号 |
| **确认密码** | 再输入一次 |

## 面板地址 {#panel-address}

面板监听在哪里，以及它响应的路径。

| 字段 | 作用 |
| --- | --- |
| **监听 IP** | 留空表示所有接口，IPv4 和 IPv6 都监听。填写一个地址则只绑定该地址 |
| **端口** | 面板监听的端口。初始值是安装程序选择的端口 |
| **面板路径** | 面板在这个路径下提供服务。默认给出一个随机路径；留空则在根路径提供面板 |
| **订阅路径** | 订阅链接以这个路径构建。它必须与面板路径不同 |

请保留随机的 **面板路径**。这样即使有人找到了你的端口，也找不到登录页。每个路径旁的刷新按钮会生成一个新的随机路径。

在 Docker 中，监听地址由 compose 文件固定，两个监听字段显示为灰色。

## HTTPS {#https}

**通过 HTTPS 提供面板** 默认开启。面板会签发自己的证书，并在到期前续期。

- **证书地址** 会预先填入你打开向导时使用的地址，页面还会列出它在本机上找到的其他公网地址。请核对：面板无法知道你的浏览器会使用哪个地址。在 NAT 后面或容器中，公网地址可能不在任何网络接口上，缺少时请手动添加。IPv6 地址直接书写（`2001:db8::10`）。
- **面板域名** 可选，且必须已经解析到本服务器。证书会重新签发以覆盖它。
- **订阅域名** 可选，使用同一张证书。客户的链接会用它来构建，而不是面板的地址。

你可以关闭 HTTPS，但必须勾选 **我了解风险，仍使用普通 HTTP**：不使用 HTTPS 时，密码和订阅链接会以明文在网络上传输。

面板签发的证书是自签名的，因此设置完成后浏览器会警告一次。接受警告并继续即可。以后要使用 CA 签发的证书，见 [[use/certificates]]。

## 区域 {#regional}

**时区** 决定面板中所有日期和时间的显示方式。**服务器时区** 使用服务器自身的时区。

## 保存并启动 {#save-and-start}

表单底部的 **面板将可通过以下地址访问** 显示你所填写的完整地址。请把它记下来，包括路径。**保存并启动** 会保存全部内容，并让面板在该地址上重启；页面会倒计时，然后打开新地址。

如果之后无法访问该地址，所有这些设置都可以在服务器的命令行中修改；见 [[reference/cli#locked-out]]。

这是面板的第一个地址。之后你可以在 [[use/ingress]] 中把它换到带域名的 443 端口、添加更多端口和主机名，或者把其他程序放在它后面。

## 改为还原备份 {#restore-a-backup-instead}

要把现有的 Nexora 面板搬到这台服务器，请在向导底部选择 **从另一台服务器迁移？从备份还原**，而不是填写表单。

1. 把备份归档拖到页面上。加密的归档会要求输入口令。
2. 页面会显示归档的内容：备份时间、由哪个面板版本创建、来自哪个地址，以及多少行数据。任何异常都会给出警告。
3. **还原并重启** 用归档替换这个空数据库。

归档必须来自与本次安装相同的面板版本；来自更旧或更新版本的归档会被拒绝。请在这里安装旧服务器的版本（`--version`，见 [[install-panel]]），还原，然后再更新。

面板恢复后就是原来的服务器：它的账户、节点、用户和证书，以及地址设置。这些地址设置不一定适合这台服务器。如果旧地址在这里无法使用，面板会退回到它启动时所用的地址。请用旧服务器上的账户登录。

许可证会随归档一起迁移，但仍绑定在旧服务器上。请在 **许可证** 页面中转移它；见 [[use/licence]]。

设置完成后如何备份和还原，见 [[use/backup]]。
