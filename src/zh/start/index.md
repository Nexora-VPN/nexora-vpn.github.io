# 快速开始

NX 由一个运行在一台服务器上的[[~panel]]和任意数量承载用户流量的[[~node|节点]]组成。本节带你从一台空服务器走到第一位拿到可用链接的客户。

## 需要准备什么 {#what-you-need}

- **一台运行面板的 Linux 服务器**，64 位或 32 位，带 systemd（Debian 11+、Ubuntu 20.04+、RHEL 9+ 或类似系统），或者装有 Docker。
- 该服务器的 **root 权限**。
- 面板需要 **一个开放的 TCP 端口**。安装程序会随机选择一个空闲的高位端口并打印出来；Docker 部署使用 2095。
- **每个节点一台服务器。** 面板必须能访问它的 TCP 62050 端口，用户要连接的端口也必须开放。

面板和节点可以共用一台服务器，但有所取舍：见 [[same-server]]。

## 顺序 {#the-order}

1. **[[install-panel|安装面板]]。** 一条命令，不问任何问题。结束时会打印一个一次性设置链接。
2. **[[setup-wizard|完成设置向导]]。** 创建主管理员，并选择面板的地址、路径和 HTTPS。
3. **[[add-node|添加节点]]。** 在面板中添加节点，然后在节点服务器上运行面板显示的命令，或让面板通过 SSH 安装。
4. **[[first-user|创建第一个用户]]。** 从预设创建一个入站、一个模板、把模板放到节点上、一个用户，以及应用中的一条链接。

每一步都依赖前一步。仪表盘上的 **快速上手** 卡片按同样的顺序排列，你每完成一步就会勾选一步。

## 其他入口 {#other-ways-in}

- **从其他面板迁移过来？** [[migrate]] 会把你的用户、入站和路由迁入 NX。
- **把 NX 搬到新服务器？** 在设置向导中还原备份；见 [[setup-wizard#restore-a-backup-instead]]。
- **要加一个商店或机器人？** 见 [[install-addon]]。

## 之后 {#later}

- [[start/update|更新]]面板及其节点。
- 从服务器上[[uninstall|移除]] NX。
- 出现问题时，参阅[[reference/cli|命令行]]、[[files-and-ports|文件与端口]]和[[troubleshooting]]。
