# 十分钟创建第一个用户

本页带你从一个已连接的节点走到第一位应用能够连上的客户。你需要已完成[[setup-wizard|设置]]，并有一个显示为 **已连接** 的节点（[[add-node]]）。

用户要拿到可用的链接，必须按顺序具备五样东西：一个[[~inbound|入站]]、一个包含它的[[~template|模板]]、一个运行该模板的节点，以及一个属于该模板的[[~user|用户]]。仪表盘上的 **快速上手** 卡片跟踪的也是这些步骤。

## 1. 从预设创建入站 {#1-create-an-inbound-from-a-preset}

入站是用户连接的协议和端口。

<NxShot page="inbound-new" alt="从预设添加入站，列表第一项是 VLESS + REALITY" />

1. 打开 **入站**，点击 **从预设添加**。
2. 选择 **VLESS + REALITY**。它通常是第一个入站：不需要你自己的域名或证书。
3. 普通的入站表单会打开，并已填好内容。此时还没有创建任何东西。检查端口；其余内容可以保持预设的值。
4. 保存。面板会自己生成 REALITY 密钥对和 short ID，无需生成或粘贴任何密钥。

之后每个字段都可以修改，也不会记录入站是由哪个预设创建的。其他预设和所有选项见 [[use/inbounds]]；协议本身见 [[vless-reality]]。

## 2. 放进模板 {#2-put-it-in-a-template}

模板就是节点提供的内容：入站、出站、端点和路由。

1. 打开 **模板** 并添加一个。填写 **名称**。
2. 在 **入站** 下选择第 1 步的入站。
3. 保存。

路由和 DNS 选项卡可以先不管。需要时见 [[use/templates]]。

## 3. 给节点分配模板 {#3-give-the-node-its-template}

1. 打开 **节点** 并编辑你的节点。
2. 在 **模板（入站 + 出站 + 端点 + 路由）** 中选择该模板。
3. 保存，等待节点再次显示 **已连接**。

在拥有模板之前，节点不提供任何服务。如果节点服务器上运行着防火墙，现在开放入站的端口。

## 4. 创建用户 {#4-create-a-user}

<NxShot page="user-new" alt="新用户表单：名称、流量、到期时间和模板" />

1. 打开 **用户** 并添加一个。
2. 填写 **名称**。设置以 GB 为单位的 **流量**（0 表示不限）和 **到期时间**；或者勾选 **从首次连接开始计算** 并填写 **套餐时长（天）**，这样时间从客户首次连接时开始计算。
3. **模板** 保持 **全部模板**。新用户默认可以访问所有模板。
4. 保存。凭据会自动生成。

套餐、限制以及此表单上的其他内容见 [[use/users]]。

## 5. 把链接发到应用 {#5-send-the-link-to-an-app}

在用户所在行打开 **二维码 / 链接**。

- **订阅** 包含用户的[[~subscription|订阅]]地址及其二维码。通常你分发的就是它：应用会自行重新获取，所以之后的修改无需新链接就能到达客户。
- **链接** 为每个条目提供一条分享链接，适用于只接受单条链接的应用。

导入到应用中：

| 应用 | 平台 | 方法 |
| --- | --- | --- |
| v2rayNG | Android | **+** 菜单，从剪贴板导入，或扫描二维码 |
| Hiddify | Android、iOS、桌面 | 从剪贴板或二维码添加配置 |
| Streisand | iOS | 从剪贴板或二维码添加 |
| SFA (sing-box for Android) | Android | 用订阅地址添加远程配置 |

在浏览器中打开订阅地址，会显示用户的[[~subscription-page|订阅页面]]，包含用量和导入按钮。详情见 [[use/subscriptions]]。

::: warning 两种看起来像链接坏了的情况
- 在 v2rayNG 和其他基于 Xray 的应用中，**Mux** 必须保持关闭。开启后连接会无声地失败。
- v2rayNG 只更新屏幕上当前显示的订阅分组。请先选中新分组的选项卡，再更新。
:::

## 6. 检查能否连接 {#6-check-it-connects}

在应用中连接，然后打开一个网页。回到面板，一分钟内用户所在行就会显示流量，节点的 **连接** 列表也会显示这条打开的连接。

如果连不上，见 [[troubleshooting#users-cannot-connect]]。
