# NX Shop

NX Shop 是官方[[~addon|插件]]，用于向客户销售面板的[[~plan|套餐]]：商品、订单、钱包、卡对卡转账和网关支付、Telegram 机器人、网页应用、折扣码和礼品码、推荐和代理。本页介绍 Shop 的安装及其管理后台；后续页面逐一深入介绍各个部分。

## Shop 与面板如何配合 {#how-shop-fits-with-the-panel}

Shop 是独立的软件，有自己的数据库。钱在 Shop 的数据库中，账户在面板的数据库中：

- 客户在机器人或网页应用中购买，并向自己的 **钱包** 付款。
- Shop 通过你在安装时批准的令牌，请面板创建、续费账户或为其增加流量。
- 客户从 Shop 获取自己的[[~subscription|订阅]]链接。

Shop 不检查自己的许可证；由面板检查。当面板因[[~licence|许可证]]已满而拒绝创建新账户时，Shop 会立即把订单款项退回客户的钱包，告诉客户原因，通知你管理员的 Telegram 话题，并暂停新服务和试用一小时。续费和加流量照常进行。升级许可证或腾出余量后，在 Shop 的概览页点击 **重新开放销售**。

## 安装 {#install}

推荐的方式是从面板安装：**扩展 → 浏览**，选择 **NX Shop**，回答它的问题，然后让面板把它装在自己的服务器上、通过 SSH 安装，或给你一条命令自己运行。Shop 响应后，面板会完成注册。所有安装方式见 [[directory]]。

手动安装时，在 Linux 服务器上以 root 身份运行：

```bash
curl -fsSLO https://raw.githubusercontent.com/nx-panel/shop/main/install.sh
sh install.sh --method script --opt port=8095 \
  --panel-url https://panel.example.com --claim-code XXXX-XXXX-XXXX-XXXX
```

`--method script` 以 systemd 单元 `nx-addon-shop` 运行程序；`--method docker` 运行 Shop 的 compose 部署。所有内容都在 `/opt/nx-addons/shop` 下：回答在 `.env` 中，数据在 `data/` 中。

### 安装时的问题 {#the-install-s-questions}

| 选项 | 默认值 | 设置的内容 |
| --- | --- | --- |
| `port` | `8095` | Shop 监听的端口。开启 HTTPS 时，这是它唯一的端口。 |
| `database` | `sqlite` | `sqlite` 把所有内容保存在 `data/` 中；`postgres` 使用你自己运行的服务器。 |
| `database_dsn` | | PostgreSQL 连接，仅在选择 `postgres` 时询问。 |
| `admin_username` | `admin` | Shop 自己的管理员账户。 |
| `admin_password` | | 该账户的密码，10 个字符到 72 字节。之后请在 Shop 中修改。 |
| `base_path` | 随机生成 | Shop 管理后台和 API 所在的路径。客户页面（`/app/`、`/pay/`）保留在根路径，永远不会显示它。留空则把管理后台放在根路径。 |
| `public_url` | | 客户访问 Shop 的地址，`https://<host>:<port>`。开启 HTTPS 时必须写明 Shop 的端口（未写明时为 443）。 |
| `https` | 面板表单中为 `panel`，手动安装为 `off` | Shop 如何提供 HTTPS：`panel`、`acme`、`acme-http`、`self-signed` 或 `off`。见 [[shop-portal#https]]。 |

给 Shop 一个它自己的地址，不要与面板共用地址。Telegram 只通过 HTTPS 打开小程序。

### 更新和移除 {#update-and-remove}

- **更新**：再次运行 `sh install.sh`，或在面板中点击 **在其服务器上更新**。回答和数据都会保留。
- **移除**：`sh install.sh --uninstall`，加上 `--purge` 会同时删除数据。请先做[[shop-backup|备份]]。

## 快速设置 {#set-up}

在 Shop 的地址及其基础路径上打开管理后台：`install.sh` 会打印该地址，面板也可以从 Shop 所在行打开它。**快速设置** 是 Shop 自身工作的检查清单，不强制顺序：

1. **Telegram 机器人**：用 BotFather 创建机器人并粘贴其令牌。请使用 Shop 专用的机器人，不要用面板或通知器的机器人。
2. **您的 Telegram 作为管理员**：打开链接或扫描二维码，然后点击 Start。
3. **凭证群组**：把机器人加入管理员群组，在你想接收凭证的话题中发送 `/receipts`。
4. **转账用的银行卡**，如果你接受卡对卡转账（[[shop-payments]]）。
5. **商品**，从面板的套餐中选取。
6. **邮件或短信登录**，可选（[[shop-portal]]）。
7. **客户订阅地址**。

面板安装已完成的事项（注册，以及带 HTTPS 的公网地址）只有在出现问题时才会出现在清单上。

## 管理后台 {#the-admin}

Shop 的管理后台提供英语、波斯语、俄语和中文界面。Shop 的一切操作都在这里完成。

| 页面 | 用途 |
| --- | --- |
| **概览** | 今天和最近 30 天的销售额、等待人工处理的凭证、失败的订单、客户及其钱包余额、暂停的销售、与面板不再一致的账户。 |
| **订单** | 每笔购买。把失败或已完成的订单退款到钱包，取消未支付的订单，或对面板调用中断的已付款订单使用 **重新发送**。 |
| **转账凭证** | 待批准或拒绝的卡对卡转账凭证，与 Telegram 话题中的队列相同。 |
| **客户** | 按姓名、Telegram id、电子邮件或电话查找客户；编辑资料、为钱包充值或从钱包支出、查看账单、查看其服务、为其下单。 |
| **代理** | 等级和代理（[[shop-agents]]）。 |
| **报表** | 按时段和货币统计的销售额、新购与续费、续费率、热销商品和代理、促销和退款的成本、钱包余额。 |
| **商品** | 基于面板套餐的新服务、续费（按天数或自然月，可选流量和周期重置）、加流量；按货币定价；下架商品。 |
| **支付方式** | 银行卡、网关及其健康状态、支付设置、银行短信的地址和密钥、汇率（[[shop-payments]]）。 |
| **优惠码** | 折扣码、礼品码、推荐奖励（[[shop-promotions]]）。 |
| **机器人文案** | 机器人发送的每条消息，可以用你自己的话改写。 |
| **设置** | 机器人（货币、试用、需先加入的频道、充值金额、客服、提醒、自动续费）、客户语言、提醒、群发消息、邮件和短信登录。 |
| **快速设置** | 上面的检查清单。 |
| **安全** | 你的密码和两步登录。 |
| **备份** | 计划、归档、密钥，以及面板还原后的检查（[[shop-backup]]）。 |

::: warning 订阅链接与管理路径
当面板给客户的订阅链接带有面板的管理路径时，概览页会发出警告。请在 **设置 → 地址** 中把订阅链接发布在一条有自己 **路径前缀** 的 **订阅** 路由上，让客户永远看不到它（[[use/subscriptions]]）。
:::

### 机器人文案 {#bot-texts}

机器人的每条消息和每个按钮都可以按你开启的每种语言改写。文案可以使用该步骤提供的值，它们以标签形式列在编辑器下方（<code v-pre>{{.Name}}</code>、<code v-pre>{{.Amount}}</code> 等）。编辑器会用示例值预览，Shop 保存前会进行检查，因此错误永远不会传到客户那里。消息使用 Telegram 的 HTML：`<b>`、`<i>`、`<code>`、`<a href="…">`。**恢复内置** 会恢复 Shop 自带的措辞。

### 报表 {#reports}

**销售** 是指在所选时间段内付款且未退款的订单；试用不算销售。**续费率** 是指在该时间段之前售出的账户（不含试用，且仍在面板上）中，在该时间段内续费或加流量的比例。**钱包余额** 是商店当前欠客户的金额。金额按货币分别显示，从不换算。

## 客户语言 {#customers-languages}

Shop 支持波斯语、英语、俄语和中文。在 **设置** 中开启客户使用的语言。如果客户自己的语言（其 Telegram 的语言，或其选择的语言）已开启，就用该语言服务，否则用英语或第一个开启的语言。商品会为每种已开启的语言询问名称。

## Shop 的提醒，或通知器 {#shop-s-reminders-or-the-notifier}

默认情况下，Shop 会就客户的账户通知客户：到期前的提醒，以及账户到期、流量用完、续费或删除时面板发出的警告。如果你运行了为面板上每个账户做同样事情的 [[notifier]]，请在 **设置** 中关闭 **由商店通知客户到期、流量、续订和删除**，以免客户收到两次。Shop 自己做的事仍由它通知客户：购买、凭证、钱包，以及钱包余额不足而未能完成的自动续费。
