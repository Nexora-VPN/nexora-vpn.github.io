# Shop：促销

[[shop|Nexora Shop]] 有三种促销方式：折扣码、礼品码和推荐。三者都在 Shop 管理后台的 **优惠码** 页面上设置。客户在机器人和网页应用中使用它们；它们不会传到面板。

## 折扣码 {#discount-codes}

折扣码为一个订单减去一定的 **百分比** 或 **金额**。它可以限定：

- **时间段**：开始日期、结束日期，或两者都有。
- 所有客户合计的 **使用次数**（0 表示不限），以及 **每位客户一次**（默认开启）。
- **商品**：部分商品，或所有商品。
- **购买类型**：新服务、续费、加流量。

客户在选择之前输入优惠码：机器人的列表中有 **我有优惠码** 按钮，网页应用的购买页面有 **有优惠码吗？** 链接。随后列表会显示每个商品使用该优惠码后的价格。优惠码不适用的商品保持原价。不适用的优惠码会被拒绝并说明原因：不存在、已停用、尚未开始、已过期、已用完、不适用于该商品或购买类型，或该客户已经用过。

**占用。** 使用优惠码下单但尚未付款的订单会占用该优惠码的一次使用机会 **24 小时**，因此最后一次使用机会永远不会同时给两位买家，也不会被一位走开的买家一直占着。取消的订单会立即归还使用机会。占用过期后才付款的订单，仍按客户当时看到的价格成交，因此迟到的付款可能让优惠码的使用次数超出上限一次。

优惠码使其免费的订单会立即视为已付款并开通服务。优惠码从不出现在钱包账本中：订单只是要价更低。删除已被订单使用过的优惠码时，会改为停用它，那些订单仍保留其名称。

代理在其等级价格之上不能再使用折扣码（[[shop-agents]]）。

## 礼品码 {#gift-codes}

礼品码会把一笔 **金额** 存入客户的钱包，用于促销或补偿。每位客户只能使用 **一次**，可以设置结束日期和使用次数。在机器人中它位于钱包界面（**礼品码**），在网页应用中位于钱包页面。随后钱包能支付的部分会立即支付，因此有未付款订单的客户可以用礼品来支付。

折扣码和礼品码共用一个命名空间：客户输入优惠码时无需说明它是哪一种。

## 推荐 {#referrals}

开启推荐后，每位客户都有自己的推荐链接：在机器人中位于 **邀请好友** 下，在网页应用中位于钱包页面。

**首次** 通过某个链接来的客户永久归属于该推荐人。推荐关系在创建客户时确定，之后任何东西都无法改变它：其他推荐人的链接不行，管理员也不行。打开链接时已经是商店客户的人不归属于任何人。

奖励在 **推荐** 下设置：

| 设置 | 支付的内容 |
| --- | --- |
| **每笔订单的百分比** | 被推荐客户所付每笔订单的一定比例。 |
| **百分比仅限首单** | 同样的比例，但只针对第一笔订单。 |
| **首单固定金额** | 第一笔订单时支付的一笔以商店货币计的金额。 |

可以使用其中一种，也可以两种都用。两者都为零时，推荐关闭，也不显示链接。代理的等级可以设置自己的推荐比例（[[shop-agents]]）。

奖励何时支付：

- **在面板开通订单后** 存入推荐人的钱包，而不是仅仅付款之后。面板拒绝的订单会被退款，不支付任何奖励。推荐人会在机器人中收到通知。
- 试用，或优惠码使其免费的订单，不支付任何奖励。
- 订单退款会收回奖励，以推荐人钱包中仍有的余额为限。
- **第一笔订单** 是面板开通的第一笔有付款金额的订单。已退款的第一笔订单仍算作第一笔。

迄今已支付的奖励列在 **已发放奖励** 下，其成本显示在 **报表** 中。
