# 术语表

面板和本文档使用的词语。文档中任何带点状下划线的词都在这里:把指针移到上面即可看到释义。

## 面板 {#panel}

Nexora 的管理端:一个带网页界面的程序,把所有设置、用户和节点保存在自己的数据库里,并告诉每个[[~node|节点]]该提供什么服务。用户连接的是节点,而不是面板。

## 节点 {#node}

承载用户流量的服务器。它的全部配置都来自[[~panel|面板]],经由一条加密、双方互相验证身份的连接下发;如果与面板失联几分钟,节点会停止服务。

## 模板 {#template}

由[[~inbound|入站]]、[[~outbound|出站]]、[[~endpoint|端点]]、[[~rule-set|规则集]]和[[~routing|路由]]组成的命名集合,由一个或多个节点提供服务。节点提供的内容与其模板完全一致,[[~user|用户]]可以访问其所属模板的节点。

## 入站 {#inbound}

用户的入口:一个端口上的一种协议,例如 443 端口上的 VLESS + [[~reality|REALITY]],或某个 UDP 端口上的 Hysteria2。入站放在共享池中,通过[[~template|模板]]下发到节点。

## 出站 {#outbound}

流量到达节点后的出口:直连互联网、转发到另一个代理,或拦截。[[~routing|路由]]为每个连接选择出站。

## 端点 {#endpoint}

同时作为入口和出口的接口,例如 WireGuard 或 OpenVPN。WireGuard 端点的每个用户都有面板生成的独立密钥和地址。

## 规则集 {#rule-set}

域名或地址段的列表,例如某个国家的地址或某项服务的域名,供[[~routing|路由]]规则匹配。面板负责下载并更新每个列表,再自行下发给节点,因此节点从不依赖能否访问列表的来源。

## 路由 {#routing}

为每个连接选择[[~outbound|出站]]的规则:按域名、地址、[[~rule-set|规则集]]、协议等匹配。路由和 DNS 属于[[~template|模板]]的一部分。

## 用户 {#user}

你的一位客户:一个带有凭据、流量额度、到期日期,以及可选的设备、地址和速度限制的账户。用户拥有一个[[~subscription|订阅]],并连接其所属模板的节点。

## 套餐 {#plan}

创建新[[~user|用户]]时套用的一组限制(流量、时长、设备)。套餐只在创建时复制到账户上一次:之后修改套餐不会改变已售出的账户。

## 订阅 {#subscription}

用户的应用获取配置的个人地址。它按应用能读取的格式返回(分享链接、Clash、sing-box 配置、Xray JSON 配置),在浏览器中打开则显示[[~subscription-page|订阅页面]]。

## 订阅页面 {#subscription-page}

用户在浏览器中打开订阅地址时看到的页面:用量、到期时间,以及每个应用的二维码和链接。它的外观由你选择或自己编写的主题决定。

## 链接地址 {#link-address}

[[~node|节点]]在用户链接中使用的地址,可以与面板访问节点的地址不同。一个节点可以有多个地址,每个地址都会成为[[~subscription|订阅]]中的一条独立条目。

## 域前置 {#front}

放在[[~inbound|入站]]前面的 CDN 主机名:用户连接 CDN,再由 CDN 把流量转给你的节点。一个前置可覆盖提供该入站服务的所有节点。

## 隧道 {#tunnel}

两组节点之间的连接:用户连接中继节点,中继再把流量送到源节点,互联网看到的是源节点的地址。一条隧道可以同时使用多个端口和协议。

## 证书 {#certificate}

面板保管并用于入站和面板自身的 TLS 证书:自签名、由 Let's Encrypt 或其他 ACME 机构签发,或手动上传。签发的证书会自动续期。

## REALITY {#reality}

一种用于[[~inbound|入站]]的 TLS 模式,不需要你自己的域名和证书:在你的用户以外的任何人看来,服务器就像你选定的一个真实网站。保存入站时面板会生成其密钥。

## 代理商 {#reseller}

向自己的客户销售的管理员账户。它只能查看和管理自己创建的用户,并受限于流量额度、到期日期以及你允许的[[~plan|套餐]]。

## 角色 {#role}

管理员账户被允许做的事。内置三种角色(主管理员、管理员和代理商),也可以从其中一种去掉部分权限来创建自己的角色。

## API 令牌 {#api-token}

让其他程序使用面板 API 的密钥。它以所属管理员的身份工作,权限绝不会更多,还可以收窄到选定的权限。

## 事件 {#event}

已经发生的事情:某个用户用完了额度、某个节点离线、完成了一次备份。面板会把事件发送到 Webhook、Telegram 聊天、电子邮件地址和[[~addon|插件]]。

## 插件 {#addon}

接入面板的独立程序,例如 Nexora Shop 或通知器。在你批准后,面板会注册它,按其签名清单所请求的权限精确授权,并链接到它的界面;插件自行运行。

## 许可证 {#licence}

决定一个面板可服务多少用户和节点。没有许可证时,面板免费运行,最多 25 个用户和 1 个节点。

## 设置向导 {#setup-wizard}

新安装的[[~panel|面板]]打开的第一个页面。它一步创建主管理员、面板地址和证书,并且只能通过安装程序打印的一次性链接打开。
